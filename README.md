# Soulgrain Onward — Blender 面级语义标注工具 V1

本工具的目标是为长期可维护的模块化鞋模建立**可人工纠错、可保存、可验证版本的真实面级归属**，不是制作某个动画。本阶段只标注，不切割、不重建、不删除网格，也不生成外观相似的替代模型。

## 先准备什么

- Mac 上能打开 `soul.blend` 的 Blender。**云端已用 Blender 5.2.2 LTS 实测**；脚本声明最低 API 版本 4.2，但没有对其他版本逐一测试，且旧版 Blender 可能打不开本工程。先在「Blender → 关于 Blender」查看版本。
- 原始模型：<https://github.com/siriguleng15/soulgrain-onward/releases/download/soul-model-v1/soul.blend>
- `soulgrain_semantic_v1.py`。它是完整独立脚本，配置与候选规则已内置。
- 不需要在 Mac 安装 Codex、Python、pip、AI 插件或第三方 Python 库。NumPy 使用 Blender 自带版本。标注期间无需联网或 API Key。

## 从 iPad / iPhone 传到 Mac

下载工具包，在「文件」App 中解压。用 AirDrop（隔空投送）将 `.py` 和说明传到 Mac，或放到 iCloud Drive 后在 Mac 的 Finder 打开。不要把代码粘贴进 macOS 终端。

## 第一次启用：推荐方法

1. 打开 Blender，使用「文件 File → 打开 Open」选择你的 `soul.blend`。
2. 在 Blender 顶部工作区找到 **Scripting（脚本）**。窗口窄时可横向滚动顶部工作区标签。
3. 在中间的**文本编辑器 Text Editor**里点「文本 Text → 打开 Open」，选择 `soulgrain_semantic_v1.py`。
4. 点击文本编辑器上方的 **▶ 运行脚本 Run Script**。这一步只注册工具面板，不会自动切模型或保存源文件。
5. 回到 **Layout（布局）** 工作区，把鼠标放到三维视图中，按 **N** 展开右侧栏，点击 **Soulgrain** 标签。
6. 点击 **建立标注工作副本**。在文件窗口里选择一个文件夹，使用新名字，例如 `soul_SGO_V1_WORK.blend`。不能使用 `soul.blend`，也不能选择已有文件覆盖。
7. 之后的标签、颜色、保存均发生在工作副本。面板里的 **保存工作工程** 不会写入原始 `soul.blend`。

重新启动 Blender 后，先打开自己的工作 `.blend`，再按步骤 2–5 运行一次脚本。已经保存的标签不会被重置。无需开启全局「自动运行 Python」。

可选安装方式：偏好设置的附加组件管理中，使用「从磁盘安装 Install from Disk」选择随附的 `soulgrain_semantic_v1_addon.zip`，然后启用。若版本菜单不同，直接使用上面的「运行脚本」方式即可。

## 第一次生成候选

1. 点 **生成 / 更新自动候选**，只点一次并等它结束。当前模型约 150 万个面，完整处理会有等待。
2. **洋红色 = UNKNOWN**，必须人工检查。其他颜色也只是候选，不是已确认的正式零件边界。
3. 点 **框显整鞋** 调整视野。可以拖动 Blender 三维视图右上角的坐标轴球旋转；旁边放大镜拖动缩放，小手拖动平移。已有鼠标/触控板的普通旋转缩放操作仍可使用。
4. 点 **切换分区颜色 / 原始 PBR** 对照原始纹理。本工具不重写 PBR 材质节点、UV 或图片。预览使用工作网格上单独的 `SGO_V1_PREVIEW_ONLY` 颜色属性。

候选来自已完成审计、对象/网格指纹、材质分布、面法线、位置及真实边邻接。**V1 没有调用外部神经网络或云端 AI 服务。** 对象名、材质名或包围盒都不是单独的判定依据。未匹配已审计网格指纹的对象保守保留 UNKNOWN，仍可人工标注。

本次初始候选共有 1,499,039 面，其中 722,781 面保留 UNKNOWN，3,582 面标为候选边界跨面待核对。这是保守草稿，不是识别准确率或完成度证明。原 `DEBUG_LACES_VISIBILITY_ONLY` 已知不是完整物理鞋带，因此不会整组自动标成鞋带。

## 最重要：自己纠正一个区域

例如把误归到鞋底的一块面改为鞋身：

1. 在 **编辑对象** 下拉框中选择 **主体（鞋身 / 鞋底 / 翻筒）**，点 **选择此对象**。
2. 点 **进入面选择**。首次从对象模式进入时会取消旧选择，避免误把整只鞋一起改掉。
3. 在三维视图中点选面；按 **B** 可拖框选面。也可以使用 Blender 原生套索选择工具。默认不透视选择，防止同时选到背面；需要时可使用 Blender 自带的 X-Ray/透视开关。
4. 在 **正确归属** 下拉框选择 **鞋身：未细分 UPPER**，或更具体的侧 A / 侧 B / 前鞋面等。
5. 点 **指定所选面**。工具会更新真实网格 Face Domain 标签、人工确认状态和预览颜色。
6. 出错点面板 **撤销 / 重做**，也可用 Blender「编辑 Edit → 撤销 Undo」。原生面级赋值与问题标记都参与撤销。
7. 不确定就点 **所选面设为 UNKNOWN**。这也是一个人工决定，后续自动识别不会覆盖它。
8. 点 **保存工作工程（含人工标注）**。

Blender 会把当前选中的面叠加显示为橙色。要看分区本身的颜色，可以取消选择；橙色选择高亮不是 PBR 被改坏。

侧 A / 侧 B 是源模型坐标约定：A 为 Blender Y<0 一侧，B 为 Y>0 一侧。当前尚未确认该单只鞋的左右脚身份，所以没有擅自将 A/B 命名成内侧/外侧。

## 单独查看和恢复显示

- **选同类面**：在当前对象中选中下拉框归属的面。
- **仅看当前归属**：在当前对象隐藏不匹配的面，并临时隐藏其他对象；不是删除或提取。
- **显示全部 / 取消隔离**：恢复全部工作网格面。
- **返回对象选择**：退出面编辑，再选择别的原有对象。

下拉框选择一个标签并不会直接重分配整个对象；只有点击「指定所选面」才会改标签。

## 边界穿过同一个面怎么办

不要为了看起来完整而强行给整面归类。

1. 选中问题面。
2. 在 **问题** 下拉框选择「分界穿过面 / 候选边界不明确」「真实零件融合」或「需要局部重建 / 复核」。
3. 点击 **标记所选面待处理**。这些面将保留为人工 UNKNOWN，并写入问题类型。
4. 工具不会细分、切面或重建。问题类型和源面 ID 会进入 JSON，供后续修复。
5. 如果你确认只是自动候选误判、整面确实属于同一部件，先点 **确认后解除所选问题标记**，再重新指定归属。

自动产生的“跨面”表示候选规则在该面两端出现冲突，**不等于已经确定真实裁切线**。必须人工观察，不能把它当作需要施工的指令。

## 保存、导出和重载

### 工作工程

**保存工作工程** 将面标签和状态保存到当前新 `.blend`，也保留原始 PBR。Blender 可能生成工作文件的 `.blend1` 备份；它不是源模型备份覆盖。工具还会为工作副本中未引用的原材质设置保留标记，避免重新打开时被 Blender 自动清理；不改着色节点或纹理。

### 语义 JSON

1. 点 **导出语义草稿 JSON**。
2. 保存为 `soul_SGO_V1_WORK.semantics.json` 等新文件。
3. 下次打开同一工作工程，或从同一源版本建立的新工作工程后，点 **载入语义 JSON**。
4. 默认 **导入时替换已有人工标签** 是关闭的：文件不会偷偷覆盖你当前已做的人工修正。
5. 只有你确实想以文件为准恢复旧标注时，才开启该开关。导入前先保存工作工程，便于回滚。

JSON 保存零件 UUID、名称与父级、源对象 UUID、每面归属/状态/置信值/问题类型、原始源文件 SHA-256、网格/UV/材质绑定版本指纹和源面 ID 哈希。数据不是只有一个面索引列表。

若拓扑、面序、位置、UV、法线、对象变换或材质版本不匹配，工具会拒绝载入，且在写入前先验证所有对象，防止导入一半。重拓扑后的标注迁移不在 V1 中实现。

UNKNOWN、自动候选和待处理面都不会被当作正式分界。所有导出均为草稿，`formal_boundary_certified=false`、`split_authorized=false`。即使人工面全部填写完，正式拆分仍需单独审核。

## 已验证与限制

云端 Blender 5.2.2 已对真实 `soul.blend` 的工作副本运行创建、候选、原生面赋值、人工保护、问题标记、JSON 导出/重载、版本失配拒绝、保存和重新打开等检查。原生撤销/重做使用 Blender 的真实撤销栈验证；后台测试显式建立检查点，尚未替代 Mac 上的实际点击和快捷键体验验证。最终测试明细见 `测试结果.json`。

- 不改变源文件；不切割、不删除、不重建、不导出 GLB，也不改网站或部署。
- 当前模型已有的 13 个网格对象被保留；没有另造替代模型或把同一部件再拆一遍。
- 原几何、面索引、UV、法线、材质绑定和贴图参数有保护指纹，工具自己的预览颜色与标签不计作 PBR 修改。
- 预览颜色是标注数据，不是最终产品材质。后续正式 GLB 导出应排除预览颜色属性，V1 没有提供 GLB 导出按钮。
- 没有笔刷标注，也不保证自动候选都正确。融合鞋带、鞋眼片、隐藏内衬等仍需人工面选、标 UNKNOWN 或记录局部重建问题。
- 模型面数较高；编辑主体和完整版本检查可能短暂等待。工具面板可拖宽，避免中文和长对象名被截断。
- 不要在标注过程中挤出、细分、移动顶点或改 UV；如果保护检查报错，先撤销这些编辑或重新打开最近保存的工作文件。
- Mac 实机上的面板布局、触控板操作与耗时仍需要你验证。验证后再安排正式拆分。
