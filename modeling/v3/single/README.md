## 本轮实际重做的结构

- 单只鞋为主体，不再复制成一双。辅助 GLB 的鞋身加宽，鞋帮压低；鞋带随鞋帮整体变形，不再强行保留原高度。
- 删除旧鞋底、包边等不适合的部分，以非对称鞋楦轮廓曲线重建封闭连续橡胶底，调整厚度、平直度和单色侧向凹槽；鞋头保留辅助模型的曲面并裁去与旧底相连的部分；继承鞋壳的下缘也统一裁到新鞋底接合面，清理旧网格残片。
- 翻筒具有内层根部、圆弧回折、外层下垂段及前伸下落的端部；高度和前后下摆不恒定，外层加入低频不规则褶皱。不是简单的圆柱体，也没有使用翻筒照片贴图。
- 鞋帮和翻筒之间新增内层连接网格，按平滑的鞋帮缝合轮廓搭接。搭接区域是估计的内部结构，不是从照片测量到的缝合纸样。该连接与鞋帮/翻筒有意接触，不应按彼此完全不接触来验收。
- 鞋舌采用鞋带下方根部、向上延伸段、回折顶部、短宽外垂段组成的连续厚度曲面，缩短并压低外垂段，修正上一版长而悬空的板片比例。圆角和轻微侧向变形均为真实几何。
- 翻筒两侧前缘有 8 个实际切孔和独立卷边圈。它们是结构鞋眼，使用与其余模型相同的中性浅灰白材质，没有复制照片的颜色或标识。原有下方鞋带与部分鞋眼保留，上部被翻筒覆盖的冲突段已截短封口。
- 所有模型对象使用统一无贴图浅灰白材质。无文字、印花、Logo、蒙古扣、水晶或其他装饰。

## 复现

使用现有 Blender 4.3.2，无需重新配置环境。脚本通过自身路径定位仓库。

```sh
blender -b -t 2 --python-exit-code 1 --python modeling/v3/build_single_shoe.py
blender -b -t 1 --python-exit-code 1 --python modeling/v3/validate_single_shoe.py
```

默认 CPU Cycles 64 samples，1200×900 输出六张单鞋图。当前 Blender 不含 OpenImageDenoise，因此未关闭验证或伪造降噪支持。`-- --skip-render` 只重建几何，已有图片不会同步更新；`-- --draft` 输出低分辨率快速检查图，不能当作正式渲染。

## 对照原则与剩余差距

六张照片包含双鞋和折叠/展开两种状态，不能把展开鞋筒误解成第六个独立鞋型。本候选只建一只折叠状态的完整鞋。对比中的第 4 张用于理解展开结构：只比较其中前景的折叠鞋，不宣称已经建立展开状态或布料动画。

参考相机没有标定，本轮只能进行近似观察方向的并排比较，**不是同相机精确配准，更不是轮廓误差的定量证明**。不能依据主观相似度给出虚假的百分比。

当前仍有可见差距：翻筒褶皱偏规则、布料的局部挤压和非对称塌落不足；鞋舌回折与真实布料的接触状态仍偏理想化；辅助鞋身的局部鞋楦、橡胶鞋头与后跟曲率仍有通用鞋型特征；鞋带/鞋眼细节没有达到照片中的完整工艺重建。**本轮不能宣布“足够接近参考”的最终高精度完整白模已经完成。**

自动化 Blender 脚本能生成和编辑这些真实几何，但当前程序曲面拟合没有可靠解决照片中复杂织物褶皱的精确雕刻。这是当前建模方法的能力限制；六张照片可以继续供人工建模，不应把缺少精确尺寸当成不能继续建模的理由。

需要进一步逐视角人工雕刻、缝合边界重拓扑和轮廓校正。若能补充单只鞋展开/折叠的慢速环绕视频、近距离鞋口/鞋舌连接特写、鞋长/鞋底厚度/翻筒展开长度，会减少估计；这些不是本轮未达精度的唯一原因。所有标称厚度、建模尺度、隐藏衬里、内部搭接和部分后跟结构均为合理估计，没有宣称具体尺码或制造公差。

## 校验边界与来源

校验覆盖新增封闭部件的非流形边、零面积面、非相邻三角自交，以及鞋舌/翻筒相互穿插和与其余保留鞋体的明显穿插；鞋眼卷边与布面、内衬连接与鞋帮为有意装配接触，单独排除并明确说明。整鞋并非制造用水密 CAD；部分继承鞋壳仍是开放曲面。检查通过只说明这些几何条件，不代表形似照片。
