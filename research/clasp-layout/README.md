## 打开页面

`index.html` 是完整的单文件页面，内嵌脚本、样式、两张原图及结构图，无 CDN、字体或运行时依赖。下载该文件即可保留全部功能。推荐通过任意静态 HTTP 服务打开；iPad Safari 推荐使用 HTTP/HTTPS 地址，系统“文件”的 HTML 快速预览可能不运行脚本。

在本目录运行：

```sh
python3 -m http.server 4180 --bind 0.0.0.0
```

电脑打开 `http://localhost:4180/`。iPad 与电脑处于同一局域网时，打开 `http://电脑的局域网IP:4180/`。若从仓库根目录启动服务，则路径为 `/research/clasp-layout/index.html`。云环境的 localhost 不是 iPad 地址，需要环境自身提供的端口预览地址或单独静态托管。

GitHub 文件页和 raw HTML 是代码查看／下载地址，不是已经部署的交互网页。本轮未更改部署配置、没有发布到正式网站。

## 页面功能

- A 黄金分割、B 螺线映射、C 结构延伸、D 自由几何四套起始布局不变。
- 新增 E 根号矩形、F 黄金三角、G 辅助双圆、H 3:4:5、I 圆头与偏置线相切。每套包含结构种子、自由选参、残差、工艺风险和允许的营销叙事。
- 新增与 A/B/C/D 任一固定预设并排比较；当前编辑会同步到对照图，原方案不随之改写。链接可加 `?scheme=H` 等参数直接打开指定方案。
- 切换数学辅助线、蒙古扣、关键点、原图并排对照及手绘叠加。
- 拖动两枚扣件，或分别输入中点 x/y、旋转角、锚点距离、宽度、圆头半径；支持 R 弦吸附、方向键微调、撤销和恢复。
- 显示两端坐标、间距、比例、当前约束偏差、鞋眼／缝线／区域边界和扣件之间的二维净空。
- 导出当前 SVG、3840 px 宽 PNG、坐标与公式 JSON、当前方案故事 SVG，以及结构图 SVG。导出的设计图保持矢量，PNG 按需栅格化；原图叠加仅作观察，不混入设计 SVG。
- Safari 下载未自动开始时，导出状态区提供生成文件的查看／保存链接。

切换方案会恢复该方案的起始参数。离开或刷新页面前请导出 JSON／SVG；当前编辑不自动保存，也没有 JSON 导入界面。

## 重建与检查

无需 npm 安装。修改源文件后重新生成单文件页面：

```sh
python3 build_study.py
node verify_geometry.mjs
node verify_advanced.mjs
```

新增矢量图稿可从已运行的 Chromium 调试实例导出；以下是可选的制图维护步骤，不是打开页面的前提：

```sh
node export_artifacts.mjs http://127.0.0.1:4184/ http://127.0.0.1:9237
```

该脚本保留 A–D 图稿，只写入 E–I、新故事、九方案数据和新总览。下列命令默认只重绘新实验与新总览；显式加 `--all` 才会重绘旧图。已提交的 SVG 可选用 Inkscape 重新生成高清 PNG：


`verify_geometry.mjs` 验证黄金站位、螺线半径增长和法线、C/D 方向、两端分区、鞋眼净空、扣件互撞、反向及越界负例，并核对描图与计算的鞋眼坐标。它不能评价审美或证明工艺可行。

## 如何理解结果

原图左上为 `(0,0)`，x 向右、y 向下；单位 **u 是图像坐标，不是毫米**。角度以 +x 轴顺时针计。`L` 是两端定位中心的距离，不是符号总长；`M` 是两定位中心中点，不是视觉或质量重心。

R 是参考弦，局部可偏离原弯曲布边约 10–15u，人工读点误差约 ±4u 或更多；4u 是绘图筛查裕度。A 上扣完整圆头到关键缝线仅约 0.763u，D 上扣约 2.439u，页面与图稿均保留警告。不能将这些坐标直接用于生产定位。

A 只采用黄金站位；B 明确区分精确黄金对数螺线与斐波那契四分之一圆弧；C 使用现有分割缝方向；D 不主张黄金比例。数学方法是本轮设计选择，不冒称传统蒙古服饰具有这些公式。五维比较使用解释性判断，不提供虚构的客观美学评分。


## 新实验要解决什么

| 实验 | 从鞋面哪里出发 | 几何真正控制什么 | 当前应如何使用 |
| --- | --- | --- | --- |
| E 根号矩形 | C 已使用的孔间中点 G₁，方向沿分割缝 S | 共同长边100u、短边100/√n；边线与R的交点生成中心，另外显示对角线和垂线分析 | √2有净空警告；√3/√5碰孔的子实验也公开，不能择优后反称鞋天然属于根号体系 |
| F 黄金三角 | G₁/G₂作为三角底边 | 36°顶角、72°底角的等腰腿延长控制扣轴与R交点 | 继承160u扣长时出现冲突；保留为严格几何不等于适合此鞋的负例，不推荐该预设打样 |
| G 辅助双圆 | 继承C两站，以实际圆头中心为辅助圆心 | 大辅助圆半径等于心距，公共弦与中心轴垂直，扣轴响应公共弦 | 实体小圆头仍分离；与C仅约0.89°角差，研究增量有限，不宜独立神化 |
| H 3:4:5 | G₁/G₂和同一R交界参考弦 | 方向(4,3)/5、36.8699°；通过孔间点的斜边与R交点确定中心 | 统一方向、统一规格，适合与C一起验证定位样板；4:3不是生产尺寸 |
| I 圆头相切 | 以G₁/G₂为翻筒端，用S的方向建立两条偏置辅助线 | δ=20u为设计偏距；真实圆头r=12u相切，解得锚点距约151.824u | 偏置线不是实体缝线；与H外观很近，提升主要在圆头位置的推导，不能冒称全面视觉升级 |

更完整的公式、当期坐标和取舍见 [研究说明](DESIGN.zh-CN.md) 与 [九方案比较](COMPARISON.zh-CN.md)。文化归属不因黄金、根号或双圆名称而增强；这些都是本轮当代构图方法。


## 第二轮检查与建议

已实际通过 `verify_geometry.mjs`、`verify_advanced.mjs` 和 `verify_browser.mjs`：A–D初始参数不变；E–I构造与11个手调失效案例可复算；九案切换、逐案触控拖动、角度编辑、数学线/扣件显示开关、独立A–D对照、重置、平板/手机溢出检查通过。浏览器在全新目录实际下载了新增五案的15个SVG/PNG/JSON文件，PNG均为3840×2041。SVG可解析且没有栅格图层，旧A–D图稿、结构图、参考照片及四案总览均逐字节保留。

可选浏览器检查（须已运行HTTP服务与Chromium CDP）：

```sh
node verify_browser.mjs http://127.0.0.1:4184/ http://127.0.0.1:9237
```

本轮建议深化 **C/H/I**，营销故事先用 **C/H**，工厂先验证 **C/H** 两组控制样，I留作后续定位方法对照。这是验证次序，不是最终定稿。新增案中最值得继续的是H和I：前者把方向转成横竖可核对的坐标，后者先固定关系再求长度。相比原四案，新增价值主要是可控变量、失败记录与定位逻辑；并非每种公式都创造了更好的外观。

F默认160u组合有干涉，不代表黄金三角方法永远不可用；页面与文档公开112/100/96u只改扣长的检查，96u仅通过二维初筛，缩短40%后的穿脱和开合尚未验证。E各根号子实验也保留失败结果。

发布副本可维护在独立 `gh-pages` 分支；源码继续使用原研究分支。当前环境对Pages网页域名的连接仍返回403，不能据此确认在线启用状态，也不能将GitHub raw下载地址当成已部署网页。正式Vercel站点没有改动。
