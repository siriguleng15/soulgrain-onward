# ONWARD · 在同一张鞋侧上推导扣位

本轮延续已经确认的独立侧片模型，不移动原裁片坐标，不改变展开形变。新增的是依附这张面片的几何画线、两组皮条与扣件的观测位置、带编号的表面点和覆盖范围。照片是数字化输入与复核依据，不作为贴在模型前方播放的画面。

## 推导顺序与依据

过程沿用用户给出的八张推导图及最终皮条图：先区分鞋身与翻筒安装区域，再延伸原缝线、连接区域前端与翻筒右上端、建立左侧安装边界；随后画出方向辅助线、黄金矩形分割与前五段四分之一圆弧，展示第五段支撑圆，再定位两枚原图蓝色扣心，最后形成两组皮条与覆盖范围。

这里的圆弧体系来自原图中实际使用的黄金矩形模板，比例为 `φ=(1+√5)/2`。前五段圆弧半径为 `1, φ⁻¹, φ⁻², φ⁻³, φ⁻⁴`；这是递归正方形构成的四分之一圆弧轨迹，不称为精确的对数黄金螺旋，也不宣称原鞋版型天然符合黄金比例。

用户已确认“以图中蓝色扣心为准，即第五段完整圆的圆心”。因此两颗扣心仍取原图观测值 `(774.121565,373.342457)`、`(812.649906,452.448903)` 照片像素，不用第四段弧的终点代替，也不为追求理想比例而挪动位置。理想模板的第五段圆心与观测蓝心仍相差约 3.59、2.98 px，保留为读图和模板拟合残差。

原图中的框架、缝线延长线及插入矩形并非严格共用三条边；“切点”沿用用户的图形推导含义，尚未证明三维缝线的真实微分相切。最终两条 PU 长轴相差约 3.329°，扣心与白条几何中点相差约 4.58、5.30 px。默认使用最终效果图的位置，不悄悄改成严格平行和严格中点的候选版。

## 为什么平铺后翻筒扣件在背面

面片的正面与背面属于材料身份，不随相机改变。鞋身上的安装覆盖标为正面；翻筒外翻后可见的安装覆盖标为背面。它们都通过原纸样三角形顶点身份及重心坐标跟随当前三维位置，而非每帧重新投影到最近的可见表面。

拆离和展开过程中，两侧安装点、覆盖面及标号跟随各自的材料区域。平铺完成后，从正面观察应看到鞋身覆盖；从背面观察应看到翻筒覆盖。二维导出分别标识正、反两面，避免将背面范围误画成正面的新增安装位置。

照片中的扣合中心只描述成鞋可见位置。公、母件各自的安装面可能对应不同的裁片点。演示中若用可见两段皮条及扣件连接状态帮助理解，这仍不等于已经恢复实际重叠量、PU 裁切长度、背部工艺或缝接余量。

## 关键点、覆盖面积与工厂使用边界

每个记录点应保留原照片位置、对应材料区域、正反面、源三角形、三个顶点身份、重心坐标和反算的二维毫米坐标。覆盖面积由映射后的平面覆盖三角形计算；它是当前数字化纸样上的覆盖参考，不能把照片平面矩形面积直接叫作真实曲面面积。

12 mm 仅为用户设定的四合扣外观直径。原鞋模单位、照片透视和面片形变没有独立实物标定，不用这一个直径推导全鞋毫米比例。PU 实际宽度、重叠量、两端缝接余量和最终裁切长度仍需实物确认；缺失参数保持未确认，不能用 12 mm 自动补出。

输出用于设计复核与后续工厂讨论，不能直接当作已经验证的冲孔／车缝工艺图。待确认内容包括鞋底包覆边界、隐藏曲面、边缘距离、孔位干涉、材料伸长、接触和公母件安装空间。

## 审核操作

1. 保持成鞋状态，播放扣位推导，观察线和圆弧在实际鞋侧逐段绘制。
2. 暂停、拖动推导进度或返回上一阶段；重新进入应得到相同几何结果。
3. 查看两个扣心、四个固定端和公母件分面位置，核对原图位置残差与待确认标记。
4. 保留最终皮条、编号和覆盖范围，播放已确认的侧片拆离、展开与叠合过程。
5. 切换正面／背面，检查鞋身和翻筒覆盖分别位于正确材料面；同一编号不能在正反面之间跳动。
6. 导出双面 SVG 和对应 JSON，核对编号、面别、覆盖面积和原始三角形身份。

## 验证方法与限制

`scripts/check-clasp-derivation.mjs` 独立核对基础面片 SHA、来源数据、黄金圆弧连续性和圆心定义；检查全部映射样点的三角形身份、重心和二维坐标，独立计算覆盖三角形面积及正反面标记，再检查实际浏览器绘制状态、求值往返、导出和触控。

截图及过程视频必须来自真实网页网格。逐帧截图编码的视频不代表实时帧率；Linux Chromium／SwiftShader 触控模拟不等于真实 iPad Safari 测试。平铺数字一致性、照片位置吻合与真实工艺可制造性仍是不同的验证结论。

## 运行、源码与资产范围

本轮交互入口仍为 `detachable-side.html`，在已确认的拆片页面上增量加入 `ClaspDerivationLayer.ts`、`ClaspPaperOverlay.ts` 和 `clasp-types.ts`。本轮扣件、曲面画线、正反面覆盖及解扣过程由网页运行时的可编辑 Three.js 几何和 `clasp-derivation.json` 驱动。

页面保留的上一轮 `detachable-side.glb` 与 `detachable-side-editable.blend` 是**已确认的纯侧片基础工程，不包含本轮新增扣件推导动画**。本轮完整结果见交互页面、源码、映射 JSON、双面 SVG 与过程视频；不能用旧 GLB 的存在宣称新增推导已烘焙到该文件。

在仓库根目录生成、构建与测试：

```bash
python3 modeling/detachable-side-panel/build_clasp_derivation.py
npx tsc --noEmit
node scripts/build-detachable-side-preview.mjs /tmp/onward-clasp-preview ./
python3 -m http.server 4498 --bind 127.0.0.1 --directory /tmp/onward-clasp-preview
```

另一个终端运行：

```bash
node scripts/check-clasp-derivation.mjs http://127.0.0.1:4498/detachable-side.html
```

加 `--video` 可在检查通过后记录实际网页几何与连续翻面镜头，需 FFmpeg。源纸样、已确认面片和 V10 模型保持只读；不重新运行基础面片生成来覆盖用户已确认的几何。

独立预览入口：<https://siriguleng15.github.io/soulgrain-onward/onward-clasp-derivation/detachable-side.html>。成果、正反面 SVG 与验证证据入口：<https://siriguleng15.github.io/soulgrain-onward/onward-clasp-derivation/detachable-side-panel/clasp-review.html>。只追加该预览目录，原网站与上一轮预览不覆盖。
