## 已实现的控制

- 正向播放、暂停、重播、独立倒放收回、取消／复位。
- 0–100% 进度拖动，任意顺序正向／反向查看。
- 0.25×、0.5×、1×、2×、3×，实际改变时间推进速度。
- 矩形轮廓和实体带状共用中心路径、位置及法线缓冲；切换不重设姿态。
- 显示路径与控制点，点击三维控制点或下拉选择，通过 X/Y/Z 输入编辑偏移；原皮条三个锚点锁定。导演冲刺的最后两个点锁定，其余可编辑点会实际影响曲线。
- 自由旋转与缩放；侧面、后面、斜上方预设；一键平滑恢复导演镜头。
- 参数 JSON 导出与路径／参数重置。当前没有文件导入控件，可通过 UI 重填或在源码中维护导出的参数。

| 参数 | 默认／范围 | 实际影响 |
| --- | --- | --- |
| 缠绕半径 | 1.15／0.85–1.80 | 非均匀椭圆截面及随长度变化的半径 |
| 圈数 | 2.00／1–3 | 中心线绕鞋长轴的累计角度 |
| 轴向节距 | 1.00／0.60–1.35 | 纵向展开跨度和局部推进，不是弹簧物理常量 |
| 带宽 | 0.18／0.07–0.34 u | 实体与矩形轮廓的延伸段宽度；根部保持源皮条真实宽度并平滑过渡 |
| 厚度 | 0.012／0.003–0.040 u | 实体前后面、侧边、端盖；接合端厚度从零过渡 |
| 扭转幅度 | 110°／0–360° | 稳定传输坐标架上的显式滚转 |
| 空间倾角 | 0°／−35–35° | 绕鞋长轴旋转缠绕截面方向 |
| 控制点偏移 | 0／各轴−1.5–1.5 u | 中心线控制点真实三维坐标 |

u 是统一显示尺度的场景单位，不是工厂毫米。默认宽厚是广告研究参数，不是新皮条打样尺寸。

## V1.4 历史方案：后跟水平牵引与鞋身中点（转向沿用，出带及冲刺接法由 V1.5 更新）

- 修正上一版把“纵向”实现为鞋头—后跟轴滚转、且强制采用与绕行相反符号的问题。当前以默认侧面观察方向为准，只在鞋侧面内绕 +Z 单轴翻转。
- 受力点取真实后跟皮条下端，旋转中心取原鞋整体包围盒的几何中点（归一化后约为原点）。这是几何中点，不冒称实测质心；后跟节点原点不作为轴心。
- 以初始鞋侧面为参考，只考虑带根部离开方向的水平分量：`tauZ = -rY * Fx`。下端低于中点且向右拉时，结果为正，即侧面逆时针；将离开控制点改为向左时，转向相应反转。
- 用送带弧长速度控制力的代理强度，经阻尼延迟得到展示转速。转速增益与后续翻转节奏属于广告参数；它不是在世界坐标中逐帧求解绳带张力、刚体质量与惯性矩的真实动力学仿真。调试数据明确标注初始参考系、水平投影和非牛顿单位。
- 冲刺衔接增加沿离开切线的圆滑回弯，避免改转向后末圈直接折向固定世界空间路径。
- 显式采用 `T(退远) T(几何中点) R T(-几何中点)`，并验证实际鞋节点变换后的中点只随既有退远轨迹平移，不跟随后跟打转。开启路径调试时，用十字标记显示中点。
- 使用真实鞋模顶点的侧视投影检查逆时针方向，而非仅检查四元数符号；另测试反向拉力、恒定转轴、中点不漂移及任意进度复位。原先后跟特写、顺势送带、慢慢拉远及全部调试操作保留。

## V1.3：顺势出带与后跟特写（沿用）

- 停用原先先外抬皮条、再延长红带的几何动作。原皮条与缝线保持真实源曲面和原法线，红带从下端沿实际表面切线送出。
- 起始段改用弧长推进，短距离内平滑加速后匀速送出；厚度按真实伸出距离形成，极短红带不会突然出现厚端头。
- 红带表面直接求值连续样条曲线，并将宽向重新正交化，避免在特写下出现调试折线采样带来的细小折面。调试线只供显示，不再决定表面位置。
- 开场0–3s先推进到后跟；3s开始出带；3.6–12.9s缓慢拉远，接回原有纵向旋转、两圈绕行和冲刺。新增的相机时间与原动作时间分开，均可暂停与任意进度逆向查看。
- 特写推进中也可点击连续返回，从当前真实相机位置与目标平滑回到整鞋。自由相机仍可随时接管；恢复导演镜头的短暂交接期间停留在当前叙事时间，避免近景目标继续移动而在交接末端跳变；交接后续播。
- 原 GLB、UV、纹理、正式展示页面保持不变。本版本仍是广告表演，不是皮革流动或布料制造仿真。

## V1.2 历史方案：沿鞋身长轴旋转（转轴与方向已由 V1.4 替代）

按用户艺术反馈，停用 V1.1 的俯仰、偏航和横向转矩。鞋子仅围绕鞋头—后跟的 X 轴旋转，保留与绕行进度对应的转速、阻尼延迟及连续逆向复位。位置采用平滑退远轨迹，取消随牵引方向变化的局部摆动。

红带仍从原后跟皮条的下端向下、斜外方引出；红带路径、矩形轮廓／实体两种模式、自由观察和所有几何调节保持可用。空间倾角和路径点可以改变红带形状，但不会再使鞋子产生侧向翻转；圈数仍实际改变鞋子的纵向旋转总量。

新增检查要求任意采样的鞋子四元数 Y/Z 分量、角速度 Y/Z 分量为零，并验证路径倾角／控制点变化不会改变旋转轴。验证结果见本版 validation.json。

- 路径方向改为上端→中部→下端，红色延长段与源皮条下端 UV 边连接。反转的是派生几何的路径参数，不是原 UV、源顶点或产品设计。缝线的长向／法向符号同步调整。
- 下端之后先向下、向后跟外侧引出，第一圈从鞋底下方起绕，再沿负 X（鞋头方向）推进。上端不再伸出红带；引出段与翻筒用实际渲染顶点及翻筒模型包围范围做回归检查。
- 鞋子运动由同一路径求得：取生长前端方向与切线的加权牵引方向，以真实下端锚点形成力臂，计算斜向转矩；绕长轴的角动量响应与绕行方向相反。使用带阻尼延迟的四元数积分，形成同时变化的滚转、俯仰与偏航。
- 采用固定480步的规范时间表，参数或路径点变化时重新计算。每帧及任意进度拖动只采样位置与四元数，不按实际帧率累加积分。因此反向查看、完整回归和从当前状态连续返回共用同一条轨迹，不产生累计漂移。
- 这是**路径驱动的广告惯性近似**，不是已测质量／惯性矩的刚体动力学或真实皮革仿真。绕行段目前仍随鞋体局部坐标运动，尚未引入独立世界空间绳带张力或接触求解。
- 新增验收覆盖下端连接、向下斜出、引出段低于翻筒、多轴延迟响应、空间倾角／控制点实际改变鞋子运动。原有播放、反向、返回、触控、两种模式及源资产保护继续验证。

## 第一轮艺术审核应关注的差距

- **穿模：**默认轨道存在包围盒候选预警；盒内不等于实际穿入布面，盒外也不等于完整碰撞证明。尚无布料接触、自碰撞或网格级约束求解。任意缩小半径、增宽或拖动点可能产生真实穿插，应在三个观察角度逐段审核。
- **扭转：**使用稳定移动帧和显式滚转，避免任意法线跳转；默认轨道有局部急弯，矩形边框在掠视角会变细，控制点编辑过猛仍可能出现不理想折痕。反向切线计数与最小相邻帧点积保留在诊断 API 中。
- **透视：**冲刺目标固定在导演空间，正常导演镜头不应穿过 near plane；自由观察及其他预设不会改变这条路径，因此冲刺末端可能位于观察画面之外。它不是相机追逐特效。
- **回归：**接合段已约束到原皮条当前边界，原图案和缝线恢复；这是广告曲面变形，不是真实皮革力学。极接近停止点的材质与曲率过渡仍需慢速艺术审核。
- **材质与尺寸：**沿用有限分辨率的 V8 照片材质与织物近似法线，红色带为简单 PBR；没有为微距补造热压细节。没有黑膜、粒子、后期、文案章节或正式广告整合。
- **性能：**原模型约46万三角形，实体带新增约1.56万，轮廓约0.37万。CPU重采样与高分辨率软渲染可能降帧；记录里的软件帧时间不能替代真实桌面 GPU／iPad 实测。

V1用于审核运动、空间构图和可逆控制，不宣称达到最终电影级效果。硬件性能、准确碰撞约束和更细的曲率／节奏修订留待后续艺术反馈。

源资产的基础鞋体署名沿用仓库记录：theunclerulez / Generic “Converse style” Sneakers，CC BY 4.0；Soulgrain产品图稿与定稿设计沿用用户提供资产。GLB内来源元数据保持不变。

## V1.6 历史修订：向鞋头推进、近镜宽面
