# 用户扣件设计的像素反求与工程边界

本说明只研究本次真实设计图，不沿用旧 A–I 研究页的扣位。默认始终保留用户最终图中的位置；“约束校正候选”是检验文字规则的独立候选，默认关闭，尚未定稿。

## 资料与坐标

全部原参考按原始字节保存于 `public/pattern-engineering/references/`，其中 `03` 是 1280 × 894 的原鞋侧照，`04–11` 是八步设计过程，`12` 是最终两条白色 PU 的效果图。这里的坐标原点在照片左上角，X 向右、Y 向下，单位是 **照片像素**。它们既不是裁片坐标，也不是成鞋毫米。

`clasp-design.json` 记录输入图片 SHA256、颜色分割规则、拟合结果、残差与待定工艺参数。运行 `python3 scripts/pattern/check_clasp_geometry.py` 可从原图再次生成，使用 Pillow、NumPy、SciPy，不调用图像生成工具。提取结果小数位用于复算，不能据此宣称亚像素生产精度。

## 黄金图确实提供了可解释的定位关系

从 `07` 和 `09` 与原框架图的亮度差分中提取插入参考图，先拟合其旋转方向，再扫描内部灰色矩形边框。不能把含文字和留白的整张白色图片外框当黄金矩形。

两次内部框观测宽高比分别约 **1.61560、1.61681**，与 `φ=(1+√5)/2≈1.61803` 接近，差异约 0.15% 和 0.08%。这里是用户确实插入了黄金构图底稿，不能反过来说原鞋版型、缝线或制造尺寸天然符合黄金比例。参考内框采用带约 2 px 读图不确定性的旋转等比拟合。

轨迹按黄金矩形的递归正方形生成四分之一圆弧。它是常见的圆弧近似构图，**不是精确的对数黄金螺旋**。规范化矩形为 `[0,φ]×[0,1]`，前五段半径为 `1, φ⁻¹, φ⁻², φ⁻³, φ⁻⁴`。另一颗扣头使用 Y 方向反转的同一圆弧体系；没有任意在鞋侧新增两条装饰螺旋。

必须区分两个不同的几何点：

- 第四段圆弧终点为 `(1, φ⁻³)`。
- 第五段四分之一圆所依托的完整圆圆心为 `(1+φ⁻⁴, φ⁻³)`，半径为 `φ⁻⁴`。

第四段末端位于第五段完整圆的圆周上，**不等于该圆的圆心**。用户图中的两枚蓝色圆心距第五段支撑圆圆心约 **3.59 px、2.98 px**；距第四段弧末端约 **23.31 px、23.41 px**，接近蓝圆半径。**用户已于 2026-10-28 确认：“以图中蓝色扣心为准，即第五段完整圆的圆心”。** 因此定位含义已经明确，默认位置仍取最终图的蓝色扣心，不为追求理想几何而将其移动到模板拟合中心。程序保留圆弧末端和支撑圆圆心，供核对手绘与拟合的剩余误差；用户的确认不等于宣称误差为零。

源图蓝圆直径约 47 px，支撑圆拟合直径约 51 px，仍有约 8–9% 的图形尺寸差，不能虚报完全重合。12 mm 是用户给定的扣头外观直径；由于原照不是经过标定的统一平面，不从这一数值反推出全鞋照片的毫米比例。

另外，参考矩形与绿色框架的三边重合并非精确：顶部和左侧约数像素，右下端与第二条缝线延长线有约 18 px 的差异。该偏差保留在 `frameAgreementPx`，不通过变形用户原图或改扣心来掩盖。

## 公母扣、重叠与裁切

完整皮条的视觉中点、两段 PU 裁切长度、公母扣安装中心、扣合重叠和沿曲面长度是不同量。当前未提供 PU 实际宽度、重叠量、两端缝接余量，因此这些字段为 `null`，不从 12 mm 扣头直径生成任何默认数值。

若后续确认对称重叠的构造，设鞋身固定端至扣心的曲面弧长为 `Lbody`，翻筒端至扣心的曲面弧长为 `Lcuff`，重叠 `O`、两端缝接余量分别为 `Sbody、Scuff`，则候选计算为：

```
鞋身段裁切长度 = Lbody + O/2 + Sbody
翻筒段裁切长度 = Lcuff + O/2 + Scuff
扣中心距重叠端头 = O/2
```

这只是 **已明确命名的对称重叠假设**。即使投影视觉扣心是完整白条中点，`Lbody` 与 `Lcuff` 也未必相等。`cutPlan()` 在参数不全时返回空裁切长度；三维假设尚未实物验证时即使参数齐全，仍返回 `productionReady=false`。

公母两件在扣合处存在两个接触面，可能对应两个不同的裁片点。单一可见像素不能自动恢复两张接触面的毫米位置；需要分别选定表面三角形身份，再通过同拓扑重心坐标回映到原裁片。每个固定端与公母安装点应单独标识，并对缝份、翻折区、边缘距离和遮挡区域做检查。

## 可复算验证

交互模块提供 `CLASP_PROCESS_STEPS` 与 `claspProcessOverlaySvg(design, step)`，按八个过程节点与最终效果返回原照片像素坐标中的可编辑 SVG 图层。1–8 分别对应原图 `04–11`：区域、结构框架、辅助定位线、第一模板、第一扣心、反向模板、第二扣心、双扣心。第 9 项为 `12` 最终皮条效果。`claspOverlaySvg()` 仍保留原有图层开关；约束候选默认关闭，打开时带有“未经定稿”标识。

```
python3 scripts/pattern/check_clasp_geometry.py
node scripts/pattern/check_clasp_geometry.mjs
```

检查内容包括原图拟合数据、四分之一圆弧连续性、第四末端位于第五支撑圆圆周、正反模板坐标变换往返、默认观测版保留、严格候选中点约束、未知工艺参数的裁切输出阻断，以及曲面两段长度不同的情况。此检查不等于实物位置精度验证。
