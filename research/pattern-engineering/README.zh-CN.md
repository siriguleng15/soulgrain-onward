# SoulGrain ONWARD · 真实裁片工程研究 V1

本项目把用户提供的工厂纸样数字化，并建立保留顶点身份的二维／三维薄片研究工具。**目前能验证数值对应和可逆展开，不能声明已经还原真实缝合、绷帮和隐藏折叠工艺。** 默认成形状态是一组公开、可调整的照片拟合假设；所有反向定位结果均为待实物复核的研究参考。

[在线交互预览](https://siriguleng15.github.io/soulgrain-onward/onward-pattern/pattern-lab.html) · [默认假设定位 SVG](https://siriguleng15.github.io/soulgrain-onward/onward-pattern/pattern-engineering/exports/ONWARD-reference.svg)

独立入口为 `pattern-lab.html`，开发分支为 `feat/onward-pattern-engineering`。新文件集中在 `src/pattern-engineering/`、`public/pattern-engineering/`、`scripts/pattern/` 和本目录。原官网、设计工作台及既有 V7／V8／V9 鞋模不是本项目的编辑对象；构建脚本只打包这一页及其资料。

留出网格残差 RMS 为 **0.390 mm**，最大交点残差约 **1.479 mm**。这只是所选单应模型对网格交点的解释程度，不是纸样轮廓的不确定度，也不是工厂允许公差。垫板网格实际间距、纸张翘曲、镜头畸变和手工描线误差尚未独立实测。

## 六个研究阶段怎样查看

1. **标定与轮廓**：左侧查看毫米轮廓、10 mm 网格、鞋眼和参考线；调节校正照片透明度。右侧查看原照片上的网格审计。C 图图层仅按其自身标注显示，允许看到不一致。
2. **对应网格**：查看从真实轮廓与孔位生成的三角网格。轻点任一视图的面料，另一侧显示同一表面位置和三角形身份。孔内不提供面料绑定。
3. **展开与翻折**：拖动进度或播放动画。修改假设的轴、角度、弯曲带和后跟包覆，观察同一个网格的变化。完整展开始终回到源毫米坐标。
4. **成鞋校准**：用侧视照片透明叠加检查当前假设。可先点左侧裁片，再在右侧照片添加投影约束。人工约束会改变局部伸长；需要同时检查应变，不能把“贴合照片”视作真实工艺证明。
5. **扣件推导**：按八步过程及最终效果逐步查看框架、正反黄金矩形四分圆、蓝色扣心和皮条；可切换对应原图。默认是观测版。平行／中点校正候选默认关闭，未经用户定稿。
6. **反向定位**：先检查成鞋假设，再执行“投影并锁定扣位”。四个固定端及两颗扣心各自的鞋身／翻筒投影分开记录。锁定后，展开只改变三维位置，不改变三角形和重心坐标。形变参数修改后需重新投影核对。

二维视图支持单指平移、双指缩放；三维支持单指旋转、双指缩放。无操作时不持续播放展示动画。本工具优先用于几何检查，不使用写实材质或鞋底来掩盖几何差异。

## 可追溯的几何关系

### 纸样坐标

原图像素 `p = (u,v,1)` 与校准毫米 `q = (x,y,1)` 通过 `q ~ H·p` 相连，除以第三分量得到实际坐标。`pattern-mm.json` 同时保存 `sourceToMm`、`mmToSource`、输入交点、划分及残差。毫米坐标原点为裁断轮廓外接框左下角，X 向右、Y 向上。

`pattern.svg` 和 `pattern-mm.json` 保留原外轮廓、13 个鞋眼及 4 个用途未确定的内部标记。两条横向线保留为观察到的结构参考；它们没有被冒称为已知工厂翻折线。原图手写的“7 mm”也未自动解释为缝份。

### 固定拓扑与连续形变

网格保存不可变 `flatMm[i] = (x_i,y_i)`、`vertexIds[i]` 和三角索引。当前最大边长设为 4 mm，共 **8,453 个顶点、16,125 个三角形**。E03、E12、E13 的照片孔轮廓有自接触／像素断裂，计算网格对这三孔采用观测圆心、半径的 24 段近似；原始观测轮廓仍保留在纸样数据和 SVG 中。不能把近似计算孔边当作已测准的裁切孔形。

给定翻折轴点 `h` 和方向角 `α`，源点在轴向和法向的坐标为：

```text
s = (x-hx) cosα + (y-hy) sinα
d = -(x-hx) sinα + (y-hy) cosα
```

在假设的宽度 `w` 内做圆弧弯曲，`θ = t·θfinal`、`r = w/θ`；弯曲带后为同一片上部面料的刚性转动。`θ → 0` 时直接返回平面。后跟包覆和可选人工高斯约束也从原坐标计算。每一帧均重新求 `P_i(t) = F(flatMm[i],t,parameters)`，不对上一帧位置累加，所以反复展开不会积累坐标漂移。

此构造的直轴法向截面具有解析弧长关系，但离散三角形、后跟包覆及人工约束可能产生伸长。默认照片假设下离散主伸长范围约 **0.9714–1.0316**，不是完全等距，更不是经过材料实验验证的布料应力结果。

### 双向定位

选中三角形 `j = (i0,i1,i2)` 上的重心权重 `λ0+λ1+λ2=1`：

```text
二维位置 q = Σ λk · flatMm[ik]
三维位置 P(t) = Σ λk · formedMm[ik](t)
```

导出的工程文件同时保存三角索引、顶点身份和权重。换观察角度、展开及折叠不改变绑定身份。照片反投影可能命中鞋身和翻筒两层，程序按明确指定的层分别求解；无命中时保持 `null`，不吸附到最近的面料。

### 成鞋照片拟合的范围

默认形态与独立 X/Y 照片显示尺度，由 12 个**人工假设的鞋眼对应点**拟合；E06 的对应不清楚，排除拟合。样本内投影 RMS 为 **10.578 px**，最大 **21.573 px**。这不是留出照片验证，也不能说明完整鞋侧轮廓已经一致。底部绷帮边、实际缝合、深度、层接触和隐藏部分尚未还原。

照片坐标采用 `u = ox − sx·X`、`v = oy − sy·Y`。`sx`、`sy` 是视图配准参数，不能把它们当实物统一比例尺。单张斜视照片存在多种可行形变解释，当前只是公开的一种候选。

## 扣件设计与工程边界

用户于 **2026-10-28** 确认：**以图中的蓝色扣心为准，即第五段完整圆的圆心**。第四段弧终点与第五段支撑圆圆心是不同点，程序和说明保持区别。圆弧是黄金矩形递归正方形中的四分圆构图，并非精确对数螺旋；原鞋版型和全部缝线没有被宣称天然符合黄金比例。

观测版保留蓝色扣心及最终白皮条。两条观测长轴相差约 3.329°，白条中点与蓝色扣心也有 4.584／5.300 px 偏差。不得为营销抹平这些手工效果图误差。具体框架方程、模板拟合及观测端点见 [CLASP.zh-CN.md](CLASP.zh-CN.md)。

**12 mm 只表示扣头预设外观直径。** PU 宽度、重叠量、固定端缝接范围、缝份、公母扣安装中心和曲面弧长是不同的参数。未知值保持 `null`。扣心向两层布面的投影也不是 PU 公母扣的安装孔，当前不据此生成量产裁切长度。三维金色虚线仅显示两段皮条轴线，12 mm 圆仅显示外观大小；不以猜测宽度的实体皮条冒充已验证的扣合结构。

## 交付与导出

- `pattern.svg`：真实毫米裁片轮廓和原观察结构。
- 页面“当前视图 SVG／高清 PNG”：用于检查叠加与研究展示，包含时必须注明照片或 C 图层的条件尺度。
- “定位图 SVG”：带毫米尺寸、标尺、坐标表、点位状态与非生产标记。
- “完整工程 JSON”：原裁片、标定、形变假设、人工约束、精确网格索引、点身份、当前照片配准及风险。
- “毫米坐标 CSV”：便于逐点复核；未映射点为空，不能被误读为 `(0,0)`。
- “恢复工程”：对源裁片与三角索引一致性进行检查；不允许把另一套网格的三角形编号直接套入。

SVG／CSV 显示的小数位是阅读格式，不构成相同精度的承诺。打印定位图需选 **100% 实际尺寸**，先量 100 mm 标尺，不要选“适应纸张”。在本轮实物核验完成前，所有文件仅能用于讨论和试验定位。

## 本地运行与独立构建

需要 Node.js 24 或支持原生 TypeScript 类型擦除的兼容环境；依赖以仓库锁文件为准。

```bash
npm ci
npm run dev
# 浏览器打开 /pattern-lab.html
npx tsc --noEmit
node scripts/pattern/check_mesh.mjs
node scripts/pattern/check_photo_fit.mjs
node scripts/pattern/check_clasp_geometry.mjs
node scripts/build-pattern-preview.mjs /tmp/onward-pattern-preview /soulgrain-onward/onward-pattern/
```

从原图重新数字化和重算模板需 Python、NumPy、SciPy、Pillow、OpenCV；见 `scripts/pattern/digitize.py`、`fit_photo.py` 和 `check_clasp_geometry.py`。它们用于确定性图像／几何计算，不生成或美化源纸样。更改基础几何后应按顺序重跑全部映射验证，旧三角形编号不可沿用。

独立构建不会打包既有模型和官网入口，也不合并 `main`。浏览器功能和性能测试环境应见 [VALIDATION.zh-CN.md](VALIDATION.zh-CN.md) 及配套证据；桌面 Chromium 或 iPad 尺寸模拟均不能表述为真实 iPad Safari 测试。

下一轮实物确认项见 [FACTORY-CHECKLIST.zh-CN.md](FACTORY-CHECKLIST.zh-CN.md)。
