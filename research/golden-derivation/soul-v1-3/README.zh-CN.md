# SOUL.NEW · 几何世界开场 · V1.3

本版延续黄金比例尺规推导，以用户指定的 SOUL.NEW.blend 替换旧 xiezitu 展示模型。先显示原材质鞋模，短促冲击之后进入白色线框，再接上既有推导。

## 叙事与控制

- 0–1.4 秒：完整原材质鞋模居中。
- 1.4–3.6 秒：一次光脉冲、环形冲击、轻微镜头推进，原材质切换为真实网格线框；几何网格背景出现。
- 3.6 秒以后：原 73 秒的缝线、主线、第四个穿带鞋眼下方切点、短线、翻筒分区线、两组黄金比例尺规作图与圆弧推导。总时长 76.6 秒。
- 推导时适度降低线框亮度，保证金色、青色与紫色作图线清晰。结束保留线框和推导；复位或重播从正常模型开始（默认“跟随剧情”）。
- 图层中可手动切换“跟随剧情 / 原材质 / 几何线框”。拖动模型暂停剧情并交给自由观察，导演镜头可平滑接回。
- 全部冲击状态由绝对时间计算，支持暂停、任意往返拖动、倒放、重播；没有独立 CSS 循环在暂停后继续播放。
- 减少动态偏好下关闭光闪、环形冲击和抖动，保留平缓材质切换。

## 模型来源与保护

源文件：SOUL.NEW.blend，75,893,266 字节。
SHA-256：725756904a0c71ee9c927b3e39332655c4cd175d3b9d55d0272ae70adb105183。

原工程没有保存或覆盖，没有改动原网格、UV、PBR 或语义标注。新 GLB 是独立网页导出。所有 13 个源 Mesh、1,499,039 个三角面均保留；使用逐对象、保留方向的三角形坐标集合比较，不仅比较总数。

标准 GLB 导出处理了 Blender / glTF 坐标与材质约定。为降低 iPad 纹理显存，只在派生网页副本中把一张 8192px 底色图降采样为 4096px；其他图像、材质定义以及全部几何、UV、索引、法线 bufferView 相对完整 GLB 保持相同。没有重绘图案，原 Blender 贴图未变。记录见 export.json、web-export.json。

运行时线框 Mesh 直接共享已加载鞋模的原 BufferGeometry，不简化网格、不改源顶点或索引、不把几何替换为图片。原 PBR 使用独立运行时材质克隆进行切换，复位可恢复正常显示。线框展示对象不回写 Blender 或 GLB。

## 新模型定位

旧文件的面序号和三角形锚点没有套到新模型。241 个缝线锚点重新投射到新 GLB 的真实面上，记录 node、primitive、三角面、顶点和重心坐标，重建误差小于 1e-10。

第四个穿带鞋眼仍按鞋头至鞋口计数，翻筒上的金属孔排除。鞋眼中心是空间定位点，不伪称中心空孔内存在网格面；邻近孔缘使用真实新模型表面锚点约束，并进行实际画面核对。后跟顶端依据新模型上沿顶点重新定位。切点与两组螺旋的关系保持：第一组从 P 起，第二组从同一青色短边下端 Q 起。

这些是设计演示定位，不是工厂实测。黄金矩形和切线位于明确的三维构图平面；不把它们说成鞋面曲面上的测地比例。参考图采用相接四分之一圆弧，保持原先的圆心、半径、90° 与相似矩形推导，不称作精确黄金对数螺旋。
