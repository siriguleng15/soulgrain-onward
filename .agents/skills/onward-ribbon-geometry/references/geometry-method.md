# 矩形轮廓和实体带状几何方法

## 同一参数域，两种表现

定义长度参数 s∈[0,1]，宽度参数 v∈[-0.5,0.5]。用弧长采样中心线 C(s)，取得单位切线 T 与初始宽向 B，并令 N=T×B。沿曲线用平行传输或旋转最小坐标架传播 B/N，再绕 T 应用显式角 θ(s)。清楚记录手性；不要与后跟契约中采用 B×T 的外向法线约定混用。

中面为 `P(s,v)=C(s)+v*w(s)*Bθ(s)`；非零厚度时前／后表面为 `P±h(s)/2*Nθ(s)`。w、h、边框宽度都是独立输入，必须声明单位。几何坐标架与原皮条外向通过显式符号对齐，不隐式翻转源纹理。

- **rectangular-outline**：提取同一中面的 v=±0.5 两条长边及 s=0、s=g 两条端边。它是变形矩形的闭合边界，不是随便一条红色曲线。需要立体线宽时用矩形截面条带，端角采用可控 bevel/miter；不依赖浏览器通常只支持1px的 LineBasicMaterial.linewidth，不替换为圆管。
- **solid-ribbon**：填充该中面；非零厚度时创建前后面、侧边、端盖。明确背面 UV 策略和广告假设；不要复制来源不明的皮革背面图。

模式切换保留 s/v、中心线和扭转角；两种模式在同一参数处的边界位置必须一致。用户若没有另行指定，不添加蛇头、鳞片、爬行动作、圆截面或固定螺旋图片。

## 路径、坐标架与生长

使用 CatmullRomCurve3／分段样条或可编辑参数曲线，按弧长而非控制点编号采样。曲线修改后更新弧长缓存。节点距离过近、零切向、180°反向和极高曲率必须显式处理；无法连续定义帧的尖点应拆段或加受控过渡，不能随机选法线掩盖。

传播坐标架后再施加 θ(s)，不要让 Frenet 帧的自然转动代替导演扭转。开放路径保持开放；Three.js CurveModifier 的参考实现使用闭合帧参数，不能直接照搬到开放皮条。

生长 g∈[0,1] 时，已显示部分用 s∈[0,g]，动态插值末端横边；g=0 明确定义为隐藏／无有效面。实体端盖和轮廓端边都跟随同一个 g。单独 setDrawRange 只裁图元，会产生台阶，不能作为全部生长实现。

保证采样、曲率、速度和宽度相匹配；高曲率时增密或减小宽度，不能等到自穿插才用镜头遮盖。冲刺检查相机 near plane、视锥和最大屏幕覆盖，优先真实空间运动，不简单放大原鞋。

## 原表面映射与精确回归

在原皮条 UV 上建立 s/v，与原 13×61 网格逐点关联，端点引用 asset-contract 中的 upper/middle/lower。原 UV 的 v 沿高度反向，先确认方向再映射。

保存 `P_rest(s,v)`、UV、法线和源 SHA；新增采样可用源三角形重心坐标或分片曲面插值，但不改变原节点数组。原皮条不是解析圆柱，也不是矩形平面，不能用简单 C+vB 作为最终贴合表面。

最终收敛必须以 P_rest 为目标；例如在受控末段用光滑权重混合演出表面与原表面，并用完整目标重算法线。缝线携带同一表面坐标／局部偏移或重心映射，不能只跟皮条中心平移。

仅在表面、边界、UV、法线和缝线已对齐后切回原 actor；避免两层同时可见导致深度闪烁。返回、取消、重播从规范参数计算，不在上一次顶点结果上累加。该映射服务广告复位，不构成真实皮革可展开性证明。

## 技术选择

小型带状网格先考虑 CPU 更新，便于检查法线与 Raycaster；用稳定分配的 TypedArray，避免每帧 new geometry。只有实测证明需要时再改 GPU。

GPU 方案必须同步位置、法线、深度／距离阴影、包围体和拾取。现有 CuffCurve/CuffMaterial 可参考数据纹理及阴影同步机制，但其 _sg_param 与周向翻筒假设不适用于后跟；禁止直接挂上去假装兼容。

参数检查脚本验证“规格合法”，不会证明以上运行时几何已经实现。
