# V3 范围与录屏审计纠正

用户于 2026-11-01 明确：重点不是 0 界面，而是绿色手与鼠标的整个交互过程，直到《创造亚当》式双手，要求覆盖两段录屏中所有这些效果。V2 误把范围截在解锁后的白场，本轮直接扩展同一工程。

## 第二段中实际可见的内容

| 大致时间 | 画面依据 |
|---|---|
| 0..8 秒 | 青绿/白色雾面，绿色手多种展开程度，关节/腕部蓝青色，白色圆牌绕行；部分区域被雾化遮挡 |
| 8..14 秒 | College / would / land / You 构图；手腕逐渐横向，花园背景从白场中出现 |
| 14..22 秒 | 绿色手由左侧伸出，肤色手由右下出现；双柱、云层、水面、花草、立体飘落花瓣；a JOB 文字 |
| 23..24 秒 | 中央光圈及 TAP HOLD，双手接近但保留间隙 |
| 25..26 秒 | 长按时光圈推进、整体变暗红，绿色手收握并竖起中指，肤色手保持伸出 |
| 27..28 秒 | 松开后恢复日光和原伸手姿态 |

录屏能确认画面与操作结果，不能恢复原站鼠标响应曲线、滚动距离、骨骼参数或手势识别阈值。V3 的这些参数为依据画面独立设定，并接受实际输入测试。

## 本轮对应实现

真实指针控制模型位姿；按下控制关节弯曲；滚轮/触控竖向拖动控制连续章节。绿色手后半段共享同一网格和骨骼，不切换成不同手势模型。接触使用相机 Raycaster 对中央三维球体拾取。长按值独立于章节值，释放/取消会回退；没有开发未录到的后续叙事。

场景背景为本项目新生成环境图及 2.5D Shader 处理；双手、圆牌、花瓣和接触物为实时三维。原站手模、纹理、原字体与代码没有复制；具体外观仍有差异，不标记为像素一致。

原始视频校验和、分辨率、第一段拆帧及网络访问边界保留在 [V2 审计记录](AUDIT-V2.zh-CN.md)。V1/V2 在线预览继续保留，Soulgrain 模型、网站和工作台未修改。
