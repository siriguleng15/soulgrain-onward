# 开场技术审计：已知事实与访问边界

参考：<https://why.zero.university/>；用户指定的官方开发文章：<https://tympanus.net/codrops/2026/07/17/zero-the-engineering-behind-a-defiant-interactive-narrative/>。

本环境对两个地址的普通 HTTPS 请求均返回网络代理 `CONNECT 403`，未取得原站 HTML、运行画面或文章正文。额外访问未完成。因此不能把本文称为已经完成的原站逐帧审计，也不能把下面的独立技术选择归因于开发团队。仓库中不包含来自原站或非官方克隆站的源码、纹理和模型。

目前能确认的目标来自用户任务：99 倒计时及破裂、绿色霜面、三维手部引导、实时轨迹沟槽、白色晶体边缘、闭合/圆度/旋转判断、成功后的扩散/融化/增亮，以及独立过渡场景。后续滚动叙事、破玻璃、燃烧钞票和地图都不在本研究范围。

## 独立实现选择

1. 静态生成的原创程序化晶体高度/枝晶纹理只作为材料基础，不作为动画替身。
2. 鼠标或 Pointer Events 触摸轨迹写入 GPU 双缓冲热量场，沟槽、白边和局部折射逐帧从该场计算。
3. 背景、三维模型、模糊和最终冰层合成分别绘制；成功时由真实时间控制径向、不规则晶体融化前沿。
4. 独立几何分析按弧长重采样，经过 PCA 椭圆归一化后，综合闭合距离、等周圆度、径向变异、绕转角与方向一致性判断。
5. 三维手部使用 `immersive-web/webxr-input-profiles` 的 generic-hand/right.glb。资产 README 明确声明 MIT；本地保留完整许可。原资产约 94KB、1360 个顶点，包含 25 个手部关节。独立重建父子关节链并制作食指引导姿态。

本选择不是对官方 Frost Unlock 后处理、手势阈值或手部 rig 的事实陈述。对原站的构图、绿色色值、光照、晶体细节、数字破碎方式及手部动画逐帧差距，目前均未得到现场验证。

## 可独立复现与仍需美术工作的部分

实时热量场、手势判断、状态机、重启、屏幕适配和基于 shader 的融化都能独立开发。真正达到原作冰晶的摄影级细节，通常仍需要校准过的高频冰霜材质；精细手部需要更密集的拓扑、皮肤微法线和精修骨骼动画。当前公共手部模型与程序化霜面能验证技术与互动，并不能保证原作的艺术完成度。
