# Why Zero 开场研究 V2：依据用户录屏校准

在线预览：<https://siriguleng15.github.io/soulgrain-onward/why-zero-opening-v2/>。
截图、操作视频、验证数据：<https://siriguleng15.github.io/soulgrain-onward/why-zero-opening-v2/review.html>。

本轮用用户成功上传的两段录屏作为实际视觉依据，重做 V1 的构图、冰面、手部姿态和转场；复用输入、几何识别、GPU 热量场和可取消状态机。独立分支为 `research/why-zero-reference-v2`。仅维护 `studies/why-zero-intro/`，不修改 Soulgrain 的鞋模、GLB、纹理、工作台、正式网站或 main。

V1 的已发布地址继续保留。V2 使用新的 `why-zero-opening-v2/` 预览目录，不覆盖其他预览。

## 怎么体验

- 完整开场：`./`。等待左下角倒数和顶部结霜，随后在冰面按住鼠标或用一根手指画一个闭合的 0，松开验证。
- 直接进入手势：`./?stage=hand`。
- 只测绘制与融化、不加载手部：`./?stage=core`。
- 强制验证 8 位热量缓冲回退：`./?stage=hand&byte-field`。
- 左上角箭头重新开始，倒数时的向下箭头跳过序幕；右下角月牙打开调试、质量选择、10 秒性能采样和 JSON 导出。

顺、逆时针均可；画得略呈椭圆也可。细小涂点、开放弧、直线、多圈和八字形不会解锁。失败后保留逐渐冷却的融化痕迹，再画一次不会瞬间清屏。多指接触、旋转屏幕、输入取消和重新开始会结束正在捕获的手势。

## 与录屏对应的改动

| 录屏中可见的特征 | V2 实现 |
|---|---|
| 深青绿至浅薄荷绿底色 | 线性颜色空间中的纵向渐变与轻微环境变化 |
| 冰层由上向下推进，边界参差 | 冰面高度参与结霜到达时间，连续推进的 Shader 阈值 |
| 白色数字位于左下角，随后破裂为零字样 | 本地字体图集、真实独立网格碎片与程序化侵蚀；前景绘制，不被冰层误模糊 |
| 中央只有小号 DRAW A ZERO | 移除 V1 的品牌栏、大标题和大段提示，保留无障碍说明 |
| 绿色握拳伸指，手腕与关节呈冰蓝色 | MIT 手模细分、加厚指部、腕部延伸、独立骨骼姿态和局部材质混合 |
| 手在冰后，被折射、侵蚀，且画线时仍在运动 | 单独手部 RT 经冰面法线再次取样，持续引导循环 |
| 白色引导弧、端点与绘制后的晶体白边 | 引导弧与用户热量场分开计算；真实 Pointer Events 写入动态 GPU 缓冲 |
| 画零成功后扩大、白闪、星标与白场 | 连续不规则径向前沿、白闪、独立三维四角星；随后进入短句构图 |
| You Believed 及较大的花体 B | 合法衬线字体子集、独立手绘 SVG B 与 CSS 构图；不使用原站字形文件 |

录屏中的浏览器工具栏、控制中心弹层和音频授权弹层属于 iPad 系统，不纳入网页。第二段中的手部卡牌、学院/工作场景等后续叙事仍在本次范围之外。

## 仍未等同于原作的地方

目标是按照录屏继续逼近原作，但本版不能称为像素一致：

1. 原站冰面纹理未取得；当前是新生成的原创材质，晶体具体分布和裂缝形状不同。
2. 原站手模、骨骼和动画未取得；当前为 MIT 基础上的独立可编辑衍生手模。手掌/指节比例、握合轮廓和局部光泽仍有差距。
3. 原站字体文件未取得；数字及衬线字使用合法替代字体，花体 B 自行绘制，字形不完全相同。
4. 第一段从约 78 开始可见，且开头存在系统浮层；99 到该位置的原始时长没有直接证据。V2 保留 99 开始的完整开场，该段时长是独立设置。
5. 官方技术文章仍被网络代理拦截。本文没有把独立实现归因于官方代码或官方手势阈值。

## 技术与可编辑资产

- `src/Narrative.ts`：GSAP 可取消的一次性时间线与可见时间时钟，重启代次隔离旧回调。
- `src/FrostPipeline.ts` / `shaders.ts`：手部和背景 RT、双缓冲热量场、模糊、冰面折射、结霜、沟槽白边和扩散合成。
- `src/GuideHand.ts`：骨骼父子链、握拳/拇指姿态、连续引导、关节与腕部的冰蓝色材质。
- `src/Countdown.ts`：本地图集及带固定身份的三角碎片；不播放数字视频。
- `src/NextScene.ts`：独立三维星标。
- `src/gesture.ts`：弧长重采样、PCA 椭圆归一化、闭合/圆度/绕转角/方向一致性校验。
- `assets-src/hand-refined-v2.blend`：保留细分修改器和可编辑网格、骨骼。`refine_hand.py` 可重建 GLB。
- `assets-src/frost-study-v2.png`：原创材质原图。运行时使用约 722 KB 的 WebP；不是录屏截图或原站纹理。
- `assets-src/fonts/` / `subset_fonts.py`：SIL OFL 原字体和重新命名的 ASCII 子集，保留许可。

本轮没有将用户录屏或其中的浏览器画面发布到网站，也没有把录屏用于页面渲染。

## 构建、测试与性能

```bash
cd studies/why-zero-intro
npm ci
npm test
npm run build
npm run dev
```

自动浏览器验证和审核视频：

```bash
node scripts/build.mjs /workspace/why-zero-preview-v2-local ./
node scripts/verify.mjs /workspace/why-zero-preview-v2-local --film
```

质量档位限制像素数、DPR、热量场尺寸。优先半浮点热量缓冲，扩展不可用时回退 8 位；随机量化让小于一个色阶的冷却仍可累积。仅鼠标/触摸事件更新轨迹，不重新编译 Shader。

实际验证环境为 Linux Chromium / SwiftShader 和 CDP 鼠标、触控输入，**没有实体 iPad Safari 测试结果**。软件渲染的帧间隔、审核视频的 24 fps 都不能代表 iPad 的实际帧率。右下角面板可在真实设备采样。

视频由真实触控驱动生产控制器，按固定可见时间点取帧，以便审核连续性；没有调用成功 API 或注入蒙版 uniform。浏览器截图的中间帧通过调试回调暂停已经渲染完成的帧后取得。验证结果见 `public/verification-v2/`。
