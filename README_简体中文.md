# Soulgrain Semantic V2.1 热修复：手动标注、修剪与补选

版本 **2.1.1** · 在 V2 上增量升级 · Blender 5.2 系列

## 先验证这次热修复

旧版有实际程序缺陷：普通“指定所选面”可能复用 UNKNOWN 动作参数，多对象编辑又会处理其他对象残留的选区，检查记录还会滞留。本版修复了这些路径，详见《热修复报告.md》。此前已完成的候选修剪、补选功能也保留。

打开已有 V2 工作工程，运行新版脚本，确认面板顶部显示 **V2.1 热修复 · 2.1.1**，再另存新的工作副本。不要同时运行旧 V2。

在“网格检查与人工纠错”中，把“明确的编辑对象”设为 **主体（鞋身 / 鞋底 / 翻筒）**，点击“选择该编辑对象”。如果已在模型中选好主体，也可以点“采用当前活动对象为编辑对象”。框选 15 个 UNKNOWN 面，选 UPPER，点普通“指定所选面”。成功结果必须显示明确对象、**真实回读验证成功：15 面 → 鞋身：未细分（10）**；回读区域和零件面数会自动刷新。其他对象残留选区只会说明“未处理”，不会被写入。

普通指定和 UNKNOWN 现在分成独立动作，UNKNOWN 不再污染普通按钮的参数。对象下拉与活动对象不一致时会明确拒绝，并指出双方名称；不会猜测要改谁。锁定/待处理冲突会整次拒绝，不再悄悄部分跳过。

写入后真实属性或颜色不匹配、同步/缓存刷新失败时，恢复本次全部标签、状态、置信度、问题和颜色，并验证回滚。没有通过真实回读不会显示成功。若异常导致无法验证回滚，会明确要求重新打开最后有效副本，不会隐藏错误。

最近一次写入的对象 UUID、源面 ID 列表、目标代码/UUID、校验哈希和状态保存在 Scene 的 `_sgo_v21_last_assignment` 中，随新工作 `.blend` 保存。普通用户不需要手动查看这些字段。

**现在可以修改扩展预览选区，不必重新计算。确认时提交你最终选中的面。被排除的面保留原标签、人工/自动状态、置信度、问题和预览颜色。**

工具仍处于语义标注阶段，不切割、不改变几何、拓扑、UV、材质、纹理或源面 ID。原有零件树、颜色图例、检查、手动标注、自动候选、显示控制、锁定、JSON、保存等功能保留。

## 一、下载、传到 Mac 和启动

1. iPad 下载完整 ZIP，在“文件”App 中长按 → 分享 → 隔空投送 → 选择 Mac。
2. Mac 上双击 ZIP 解压。推荐先看本 PDF。
3. 如果旧 V2 是已启用的插件，在 Blender“偏好设置 → 插件”里停用旧 V2。若以前只是运行脚本，可以退出 Blender 后重新打开。停用工具不会删除工程中的标签。
4. **打开你已有的 `soul_SGO_V2_WORK.blend`**，不要重新从 `soul.blend` 开始。
5. 顶部选择 Scripting / 脚本工作区。在文本编辑器点“打开”，选择新版 **`soulgrain_semantic_v2_1.py`**，点顶部三角形“运行脚本”。不需要 Codex、终端或另装 Python。
6. 返回 Layout / 布局，把鼠标放在模型视图内按 N，打开右侧 **Soulgrain** 标签。面板顶部应显示 **Soulgrain V2.1 热修复 · 2.1.1**。
7. 点 **另存 V2.1 工作副本（保留当前文件）**，选一个不存在的新文件名，例如 `soul_SGO_V2_1_WORK.blend`。旧 V2 文件不会被覆盖。

V2 的面属性、对象 UUID、零件 UUID、人工记录、材质和配色直接沿用；不需要重新识别、重新标注或导入 JSON。另存时验证全部标签和原版本保护数据。目标文件已存在时工具会拒绝覆盖。

也可以长期安装内层 `Soulgrain_Semantic_V2_1_Addon.zip`：偏好设置 → 插件菜单 → 从磁盘安装 → 选这个内层 ZIP → 启用。不要安装整个资料包，不要同时启用旧 V2 和 V2.1。插件随 Blender 自带的 NumPy 运行，不依赖外部服务。

只运行 `.py` 时，下次重新启动 Blender 需要再运行脚本；已经保存在 `.blend` 的标签仍在。不要在未确认预览时升级/重新运行工具，先确认或取消。

## 二、完整操作流程

1. 用零件管理器隐藏无关区域，选择要标注的**编辑对象**，进入面选择模式。
2. 在模型中全不选，再选择一个面或一小片种子。选好目标语义分类。
3. 点 **智能扩展预览**。最初橙色高亮是自动候选，尚未写标签。
4. **减选错误部分：** 使用 Blender 的框选或套索，在工具设置中切到“减选”模式，划掉错误区域。单个面可用 Shift 点击切换选择状态。
5. **补选遗漏部分：** 把框选/套索切为“添加”模式，再选择遗漏的面。
6. 可以反复减选、补选，不用重跑扩展。只要保持原对象的**面选择模式**即可。
7. 看“智能扩展”面板中的保留、排除、补充和最终面数。统计自动刷新；要立即检查可点 **立即刷新修剪统计**。
8. 只有修剪、没有补选时，直接点 **确认最终选区并写入人工标注**。
9. 有人工补选时，面板会出现红色提示。观察补选是否越界，勾选 **已检查本次补选**，再确认。改变选区后，该勾选会重置，避免把旧确认套到新的补选上。
10. 不满意则点 **取消计算 / 取消预览**，恢复预览前的面选择，不写入任何归属。

**不要再次点击“重新计算（丢弃当前修剪）”来刷新统计。** 重新计算会结束当前修剪并从原种子重新生成；只想查看最新面数时使用“立即刷新修剪统计”。改变目标分类或扩展参数仍会取消当前预览，和 V2 的安全行为一致。

面板统计按模型和选区大小约每 0.5–2 秒刷新，并非每帧扫描；确认按钮会同步重读实际选区，绝不会只相信稍早的面板数字。百万面主体测试单次统计约 0.2 秒。只在有待确认预览时轮询当前对象，不持续扫描整双鞋。

## 三、四个面数是什么意思

| 显示项 | 含义 |
| --- | --- |
| 原始 | 本次自动扩展生成的候选总数，修剪时不变 |
| 保留 | 原始候选中，现在仍被你选中的面 |
| 排除 | 原始候选中，被你减选的面 |
| 补充 | 你新选中的、原始候选以外的面 |
| 最终将标注 | 保留 + 补充，只提交这些面 |

例如原始 1,000 面，你排除 80 面，再补 20 面：保留 920、排除 80、补充 20、最终 940。被排除的 80 面不写任何属性或颜色。即使排除和补充数量相同、最终总数没变，工具也能识别选区内容变化并重置补选确认。

橙色依然是 Blender 原生选择高亮。取消橙色选中状态不会删除面，也不会修改原来的分区颜色。没有创建替代模型或永久染色来模拟修剪。

## 四、补选的保护规则

人工补选可以弥补自动法线、距离、材质或候选语义限制的不足，因此**不要求补选仍满足自动扩展的几何阈值**。这也是红色“越过原候选边界”提示的原因，需要你核对位置。

以下保护始终有效，不能通过补选或勾选“已检查”绕过：

- 已锁定分类的面，或目标分类已经锁定。
- 带未解决边界/融合/重建问题的面。
- 已被人工确认且分类不同于目标的面，包括**人工 UNKNOWN**。
- 其他对象的面。本次扩展和修剪只提交原活动对象。
- 隐藏或上下文失效、源面/拓扑版本不一致的区域。

存在冲突时面板显示红色冲突数量，确认操作会**整次拒绝，不写一部分、跳过另一部分**。请减选冲突面，或取消预览后用明确的手工纠错操作先处理原标签/问题，再重新预览。问题和锁不会被扩展自动解除。

最终选区为空时不写入。最终选区超过 **200,000 面**时拒绝，需分批标注。扩展参数中的“最多候选面”约束自动生成部分；手动补选仍受最终 20 万面硬上限保护。

如果无意选中另一个对象，工具会明确提示，请先取消那部分选择。它不会悄悄忽略其他对象而只写一部分。预览开始时会暂时清除其他编辑对象的旧面选择，取消时一起恢复。

## 五、撤销、取消和保存

**修剪时撤销/重做：** 原生选择的撤销不会强行丢弃候选集；工具保留原始候选，重新读取当前选择和对象 UUID。若撤销实际改变了标签或几何版本，确认会被阻止，要求取消并重新预览。

**确认后撤销/重做：** 使用面板的“撤销”“重做”，或 Blender 原生快捷键，可恢复确认前后的标签与预览颜色。云端测试使用 Blender 原生撤销栈的显式检查点；Mac 的实际快捷键仍以本地键位设置为准。

**取消预览：** 恢复本次预览前所有相关编辑对象的面选择、活动对象、面选择模式和临时面隐藏状态，不修改标签、颜色或材质。若你在预览中使用了原生建模命令，造成面数/源面 ID 失效，就不能保证安全恢复旧选择；工具会提示，先撤销建模操作。

**保存：** 先确认或取消预览，再保存 V2.1 工作副本。未确认的选区草稿不会导出为正式标签。第一次仍在旧 V2 文件中时，“保存工作工程”会要求先另存 V2.1，不覆盖旧工程。V2.1 的 JSON 沿用 `soulgrain.face-semantics/1.0`；现有 V1/V2 记录仍可导入。

关闭文件不会持久化未确认的候选集；请先确认或取消。原生“另存为”和建模命令不是语义锁的一部分，请不要自行把新文件保存回原工程路径。

## 六、仍保留的 V2 功能

- 零件树、名称搜索、真实配置颜色、实际面数。
- 按分类/父组件隐藏、同时隐藏多项、单独查看、恢复显示。
- 分类锁定、UNKNOWN 控制、选中分类、检查单面和多面统计。
- 手动面级纠错、问题标记、保护人工标签的自动候选识别。

分类显示仍依赖 Blender 编辑模式的原生面隐藏；需要退出时点“返回对象选择”。当前没有实际拆分任何网格。
