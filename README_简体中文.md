# Soulgrain Semantic V2 使用说明

版本 2.0.0 · 2026-11-10 · 面级语义标注阶段

**你已有人工标注：请打开 `soul_SGO_V1_WORK.blend`，再另存为新的 V2 工作文件。不要重新从原始 `soul.blend` 创建空白标注。**

V2 是真实鞋模上的零件管理和标注工具。它保存“哪些面属于哪个零件”，本轮不会切割模型，也不会补面、改变造型或制作动画。UNKNOWN 和自动候选仍需要人工判断，不能直接作为正式拆分边界。

## 1. 下载后怎样传到 Mac

1. 在 iPad 的 Safari 中下载 `Soulgrain_Semantic_V2.zip`。如果出现文字预览，请长按下载链接，选择“下载链接文件”，再在“文件”App 的“下载”中查找。
2. 在“文件”App 长按 ZIP → 分享 → 隔空投送 → 选择你的 Mac。
3. Mac 上打开“访达”→“下载”，双击 ZIP 解压。
4. 工具文件是 `soulgrain_semantic_v2.py`。不需要安装 Codex、Python、终端工具或外部 Python 库。NumPy 随 Blender 自带。

也可先看随包的 `Guide_zh_CN.pdf`。完整包不包含鞋模，不会用云端测试标注替换你已经标好的工程。

## 2. 版本与验证范围

- 目标：你正在使用的 Blender **5.2.3 LTS**，macOS。
- API 最低版本设置：Blender 5.2.0。实际云端运行环境：**Linux Blender 5.2.2 LTS**。
- 已用原始真实鞋模及包含人工标注的云端 V1 回归副本完成真实数据、操作器、持久化和性能测试。
- 你的 Mac V1 工作文件没有上传，因此不能声称已经测试了你那份文件；升级时工具会在本机逐项比对面属性和 ID。
- 云端没有进行 macOS 图形界面、鼠标操作或 5.2.3 实机验证。侧边栏回调、图标枚举、颜色预览 API 已测试；窗口宽度、Mac 快捷键及模态取消交互仍请在本机验证。

## 3. 最简单的启动方法：运行单个脚本

如果 V1 作为插件启用了，请先在 Blender 偏好设置 → 插件中停用 V1，避免两个版本同时注册面板。停用插件不会删除已经保存在网格上的标注。若之前只是运行过 V1 脚本，可以关闭 Blender 后重新打开。

1. 打开 Blender，点击“文件 → 打开”，打开你已有人工标注的 `soul_SGO_V1_WORK.blend`。
2. 顶部工作区选择 **Scripting / 脚本**。若看不到，向右滚动顶部工作区，或点“+”添加“脚本”工作区。
3. 在文本编辑器中点“打开”，选择解压得到的 `soulgrain_semantic_v2.py`。
4. 点文本编辑器顶部的三角形“运行脚本”。不要打开系统终端。
5. 回到 **Layout / 布局** 工作区，把鼠标移到模型所在的 3D 视图，按 **N**，点击右侧竖排 **Soulgrain** 标签。
6. 面板提示检测到 V1 时，点击 **另存 V2 工作副本并升级**。
7. 使用新的文件名，例如 `soul_SGO_V2_WORK.blend`。不要选 V1 文件名，也不要选 `soul.blend`。工具会拒绝已存在的目标文件，避免误覆盖。
8. 升级成功后，展开“零件管理器”。如果显示“读取标签并启动零件管理器”，点一次即可。已有人工归属继续使用。

只运行脚本时，每次重新启动 Blender 后需要再运行一次 `.py`。标注数据保存在 `.blend` 中，重新运行脚本不会清除标注。

**可选：长期安装。** 在偏好设置 → 插件页面的菜单中选择“从磁盘安装”，选择随包的 `Soulgrain_Semantic_V2_Addon.zip`，再启用 Soulgrain V2。安装的是这个内层插件 ZIP，不是整个资料包。启用插件后无需每次手动运行脚本。不要同时启用 V1 和 V2，也不要在扩展计算进行中重新运行或停用工具。

## 4. 第一次升级会保留什么

升级使用“另存新文件”，不覆盖 V1。保持原有 `sgo_part`、`sgo_status`、`sgo_confidence`、`sgo_issue`、`sgo_source_face`，以及 `_sgo_object_id`、零件 UUID 和 V1 元数据。

工具会比较升级前后的这些数组哈希，验证所有对象的几何、拓扑、UV、法线、材质面索引、变换、PBR 材质和纹理资源，并检查 V1 输入文件的磁盘 SHA-256 没有改变。

V2 只重建专用的**派生预览颜色**，修正 V1 编辑模式字节颜色可能偏暗的问题。这不改变归属，也不修改材质或贴图。界面图例直接读取实际零件配置。

第一次成功后请检查你熟悉的一小块人工标注；不需要重新运行自动识别。重新生成自动候选是可选操作。

## 5. 零件管理器：先学这五个操作

把侧边栏左边界向左拖宽，便于看清每一行。可折叠其他面板，留出空间。

每行依次显示：展开箭头、实际颜色、名称、已分配面数，以及以下按钮：

| 按钮 | 作用 | 会改归属吗 |
| --- | --- | --- |
| 眼睛 | 显示/隐藏本行范围 | 不会 |
| 单独查看图标 | 仅显示本行范围，再点一次退出 | 不会 |
| 面选择图标 | 选中该分类当前可见的真实面 | 不会 |
| 锁 | 保护该分类，防止工具误标注 | 不会 |
| 部件名称 | 设为当前目标分类；之后仍需点击指定/确认才会写入 | 不会 |

**父行包含全部子类。** 例如隐藏“鞋身（含全部子类）”，会连同鞋帮 A/B、前鞋面、后跟和后跟条一起隐藏。展开后的“鞋身：未细分（本类）”只控制直接标为 UPPER 的面。父行数字为子树合计，不应和子行数字再次相加。父行显示的多色块来自子类配置，不代表一种新材质。

可以依次隐藏鞋身、鞋舌等多个不同组件。部分子类可见或部分子类被锁时，父行会显示“半”。

**单独查看与多重隐藏分开：** 单独查看会临时只显示目标，即使它之前被隐藏。点击“退出单独查看，恢复之前的多重隐藏”后，恢复原来的组合。单独查看期间，范围以外的眼睛按钮暂时禁用；可以用另一行的单独查看图标切换目标。

**锁定与隐藏分开：** 锁定不会隐藏。被锁定分类的面不能被手动指定、问题标记或自动识别覆盖；扩展也不能跨过它们。父行锁定作用于所有后代。恢复显示不会解锁；需要点锁或“解除全部锁定”。锁保护的是本工具的语义操作，不是 Blender 原生建模命令。

搜索框支持中文名称、分类键、UUID，例如“鞋舌”、`UPPER`。清空搜索恢复整棵树。UNKNOWN 可单独查看、隐藏或选中。面数为零的分类只是可选标签，不代表模型已经有这个实体部件。

### 为什么隐藏零件后会进入编辑模式

同一个 Mesh 内的部分面只有在 Blender 编辑模式中才能可靠地隐藏。V2 使用真实网格的原生面隐藏，因此分类过滤时会进入多对象面编辑模式，不建立替代模型，不删除面。

过滤期间不要用 Tab 切到对象模式；工具会恢复过滤所需的编辑模式。需要返回对象选择时，点击面板顶部 **返回对象选择**：它会先恢复全部显示，再退出编辑。恢复显示不会更改标签或锁。

管理器接管临时面可见性，刷新/恢复时可能清除你另外用原生 H 做的临时隐藏。建议统一使用管理器控制可见性。

## 6. 点击识别与手动纠错

1. 展开“网格检查与人工纠错”。在“编辑对象”选目标对象，再点“选择该编辑对象”。融合主体通常是“主体（鞋身 / 鞋底 / 翻筒）”。
2. 点“进入面选择”。这一步会使用 Blender 原生面选择。
3. 在 3D 视图点击一个小面，再点 **检查选中面**。
4. 面板显示对象名称、源面 ID、语义名称/UUID、人工或自动状态、置信度和问题。多面选择显示各分类面数和对象分布。
5. 需要纠错时选择“正确归属”，点击 **指定所选面**。这个按钮才会写入人工标签。

检查结果来自最后一次点击检查；改变选择后要再次检查。V2 没有后台不停扫描百万面来伪装“即时识别”。对象 UUID 也会写入检查数据，但界面优先展示较易读的对象名称。

批量纠错沿用原生操作：先在 3D 视图“选择 → 全不选”，按 B 框选；按住 Shift 点选可追加，滚轮缩放、中键拖动旋转。Mac 触控板若操作不熟，先用 Blender 的视图导航图标。**不要按 G/S/R/E/X 删除或改动网格。** 不建议初次就开启 X-Ray 穿透选择，避免把背面一起框入。

“所选面改为 UNKNOWN”会记录人工确认的 UNKNOWN。它不会在下次自动识别中丢失。问题面需要先明确记录为“分界跨面 / 融合 / 需重建”，当前阶段不切割。带未解决问题的面默认不能被指定为具体部件；先核实，再使用“确认后解除问题标记”。解除后仍为人工 UNKNOWN，需要再明确指定归属。

## 7. 智能区域扩展：用一小片种子代替大面积框选

1. 使用管理器隐藏无关区域，但保留需要扩展的真实表面可见。
2. 选择正确的“编辑对象”。扩展只在**当前活动对象内部**进行，不跨对象猜测。
3. 在 3D 视图先“全不选”，只选一个面或少量小片种子。种子可以是自动候选或尚未人工确认的 UNKNOWN。
4. 选择目标分类，例如“鞋帮侧 A”。首次选“保守”强度。
5. 点击 **智能扩展预览**。橙色原生选择高亮表示候选，尚未写入归属。
6. 旋转观察边界。需要调整条件时修改参数，再重新点击预览；旧预览会自动取消。
7. 正确时点 **确认扩展并写入人工标注**。不正确则点“取消计算 / 取消预览”；计算中也可按 Esc。
8. 确认后及时保存工作工程。确认与手动标注支持原生撤销、重做；最简单的是使用面板里的按钮。

**人工确认过的其他零件始终受保护**，包括人工 UNKNOWN。若种子本身属于人工确认的其他分类，先用“指定所选面”明确纠正种子，再预览；扩展不会擅自撤销你的旧判断。

| 参数 | 作用与建议 |
| --- | --- |
| 相邻法线角度 | 小值遇到弯折更早停止；逐步增大，避免越过结构转折 |
| 偏离种子法线 | 限制扩展逐渐爬过圆滑融合部位；不会只靠局部连通无限生长 |
| 沿网格距离（尺寸%） | 沿面中心邻接路径的距离上限，相对当前对象包围对角线；不是直接用包围盒判断零件 |
| 最多候选面 | 默认 50,000，最高 200,000；达到上限是局部结果，不是完整部件认证 |
| 计算时间上限 | 约束扩展循环，默认 8 秒；首次建图、数据准备和选区更新另计 |
| 允许跨材质边界 | 默认关闭；只有确认同一真实部件跨材质时才开启 |
| 尊重其他自动候选分类 | 默认开启；关闭仍不能覆盖人工其他零件、锁定或问题面 |
| 连接完全重合的 UV/法线缝 | 默认开启；仅桥接两个端点坐标完全相同的完整边，不移动或焊接顶点 |

扩展结合真实面邻接、局部/种子法线、材质、语义、距离和人工保护条件。它是**离线几何辅助**，不调用外部 AI 服务，不能自动理解所有真实鞋类边界。过于保守时可在同一部件多选几处种子分批确认；不要为了“选完整”一次取消所有限制。

### 计算与预览的限制

- 首次对百万面主体建图是同步 NumPy 操作，本次测试约 2.6 秒；加上数据准备，首次预览约 4 秒。这一短阶段无法即时取消，计时上限不包含它。
- 建图完成后的扩展循环按小时间片执行，可以按 Esc 或点击取消。视图更新和原生选区刷新也有短暂同步开销。
- 改参数、改目标会取消旧预览；预览后自行改变候选选择，确认会拒绝写入，需取消后重做。
- 存在待确认预览时不能导出、保存或重新运行自动识别。必须先确认或取消，避免把预览当作已确认标注。
- 非流形边保守停止；没有完整共享边且端点不完全重合的裂缝不会跨越。当前主体发现 40 个无面邻居的面、2 组被阻止的非流形边；这不等于所有破损已经定位完毕。
- 如果真实分界穿过一个三角面，面级扩展不能精确表达。取消这部分归属，使用问题标记，留待后续切面/重建，不能用整个面归入某类掩盖误差。

## 8. 保存、JSON 与重载

“数据管理 → 保存工作工程”保存当前新的 V2 文件，写入面级标签、问题、UUID、元数据及显示/锁定状态；不写回原始工程或 V1 输入。重新打开 V2 文件、启用或运行脚本后，标签仍在。

建议每次完成一段明确区域后，保存 `.blend`，再 **导出语义草稿 JSON** 作为额外备份。JSON 仍采用 V1 `soulgrain.face-semantics/1.0`，包含完整零件字典、逐面压缩数据、模型与拓扑哈希；可读入 V1 JSON。默认保留本机已有人工标签。只有你明确勾选“导入时替换已有人工标签”，才允许替换。

导入前必须解除所有语义锁。任何来源/模型版本、对象集、拓扑、UV、材质资源或源面校验不匹配，整份导入都会拒绝。不能把 JSON 简单套到重拓扑后的模型上。

JSON 中的 V2 显示设置是记录信息，导入时保留当前本机显示设置。完整的工作状态以 `.blend` 为准。`formal_boundary_certified` 和 `split_authorized` 固定为 false。

“版本保护检查”会验证所有受保护数据并刷新统计。手动标注按局部更新缓存；撤销/重做或外部修改标签后会刷新缓存。若面数看起来滞后，点一次“刷新标签与面数”。若版本检查失败，应撤销建模操作或重新打开最后有效的 V2 文件，不要强行继续写标签。

## 9. 已测结果与尚需 Mac 验证

真实源模型：17 个对象，其中 13 个 Mesh；1,499,039 个三角面。主体 Mesh 为 1,063,542 面。完整结果见 `reports/` 和 `测试结果.md`。

云端测得：首次主体扩展约 4 秒；缓存后 8 个种子预览 12,296 面约 1.5 秒；2 万面批量标注约 1 秒；主体编辑模式下完整几何/UV/PBR 校验约 3.9 秒。Blender 进程峰值内存约 2.35 GiB，包含模型贴图和编辑网格；邻接图保留数组约 74 MiB。MacBook 的实际速度和内存取决于设备。

用户需要验证的短流程：升级副本 → 确认旧人工区域还在 → 隐藏鞋身和鞋舌 → 单独看鞋底并退出 → 检查一个面 → 选小种子预览/取消 → 再预览/确认 → 撤销/重做 → 保存 → 关闭重开 → 确认标签与锁仍在。先做小范围操作，确认后再标注大区域。

本工具不会保护用户通过 Blender 原生菜单进行的任意“另存为”、删除或建模操作。请始终在新的 V2 工作文件中使用语义工具；不要用原生 Save As 手动选回 V1 或源文件。工具不执行正式拆分，不把颜色图当成物理部件，也不会修改网站或动画。
