# Soulgrain Semantic V2.2 — 动态语义分解工作台

本版是在 V2.1.1 上增量升级的完整工具，无须先运行旧脚本。面级属性、对象 UUID、稳定源面 ID、人工状态和 JSON 主格式沿用 V1 / V2 / V2.1.1。工具不正式拆分模型。

## 最重要的区别

- **真实原始网格**：仍是原来的 13 个源 Mesh，顶点坐标、拓扑、父级、UV、材质索引和 PBR 不变。中心使用 Blender 可逆的面隐藏来露出未完成区域，仍能原生面选、框选、套索和智能扩展。
- **临时视觉展示网格**：从真实源面三角化坐标、源对象 UUID、稳定面 ID 和真实标签建立运行时三角面缓存，通过 Blender GPU 视口层绘制在周围。不是包围盒，也不是替代鞋模。
- 临时展示**不创建任何 bpy.data Object / Mesh / Material**，不能被选中、编辑，也不会出现在 GLB 导出、渲染或工程文件中。这比创建临时场景对象更容易避免误导出和误编辑。
- 这只是语义检查工作台，不是已经完成的实体零件拆分。UNKNOWN、候选标签和问题边界都没有因此获得正式认证。

## 下载内容

- `scripts/soulgrain_semantic_v2_2.py`：完整独立脚本，直接运行即可。
- `Soulgrain_Semantic_V2_2_Addon.zip`：安装插件用的 ZIP。
- `Soulgrain_Semantic_V2_2_Bundle.zip`：脚本、中文说明、测试源码、实际测试结果和视口检查图。**不包含模型、试验标签或用户工程。**
- `docs/技术与测试报告.md`：实现、安全规则、测试范围和限制。

## 版本和依赖

目标：用户的 Mac Blender **5.2.3**。最低声明 Blender 5.2.0。
本次实际运行：Linux Blender **5.2.2 LTS**，包括真实鞋模、原生数据操作、撤销以及实际 OpenGL 视口绘制；不是 Mac / Metal 实机测试。
仅使用 Blender 自带的 Python、NumPy、bmesh、gpu 和标准库。Mac 无须安装 Codex，也无须安装第三方 Python 包。

## 初学者安装方式一：直接运行 .py

1. 在 iPad 下载完整 `.py`，隔空投送给 Mac，记住它在“下载”文件夹的位置。若 Safari 加上了 `.txt`，先在 Finder 的“显示简介 → 名称与扩展名”确认文件最终以 `.py` 结尾。
2. 打开 Blender，使用“文件 → 打开”载入自己的 **V2.1.1 / V2 工作工程**，例如 `soul_SGO_V2_WORK.blend`。不要重新打开原始白模来替代自己已经标注的文件。
3. 若旧版以插件安装：先在“编辑 → 偏好设置 → 插件”中取消旧 Soulgrain 插件的勾选，避免下次启动时两个版本竞争。停用插件不会删除已保存标签。
4. 顶部切换到 **Scripting / 脚本** 工作区，在“文本编辑器”里选择“文本 → 打开”，打开新 `.py`。
5. 点击文本编辑器上方的三角形“运行脚本”；Mac 常用快捷键是 **Option + P**，鼠标要在文本编辑器内。
6. 切回 **Layout / 布局**，鼠标放到三维模型区域，按 **N**，右侧点 **Soulgrain** 标签。侧栏太窄时，可把它的左边界向左拖宽，避免名称和按钮被挤住。
7. 点击 **“另存 V2.2 工作副本（保留 V2.1.1）”**，使用一个全新的名字，例如 `soul_SGO_V2_2_WORK.blend`。不能选择已有文件；工具不会覆盖它。
8. 以后所有标注和保存都在这个新副本中完成。V2.1.1 工程和原始 `soul.blend` 保留。

直接运行脚本后重启 Blender，需要再次运行脚本；面级标注保存在 `.blend` 内，不会因脚本未启用而丢失。

## 初学者安装方式二：插件

1. 下载 `Soulgrain_Semantic_V2_2_Addon.zip`，不必解压。
2. 先停用旧版 Soulgrain 插件。
3. Blender：“编辑 → 偏好设置 → 插件”，使用右上角菜单中的 **从磁盘安装 / Install from Disk**，选择插件 ZIP，然后勾选新插件。
4. 打开自己的工作工程，按 N，进入 Soulgrain，先另存新的 V2.2 副本。

不要同时启用旧插件和新插件。单纯打开 `.blend` 不需要启用“自动运行任意 Python 脚本”。

## 进入工作台

1. 展开 **“动态语义分解工作台 · V2.2”**，点 **“进入分解工作台”**。
2. 初次要读入真实几何并构建缓存。大型模型可能停顿几秒；随后按块构建并显示进度。初始构建中可按 Esc 取消，源显示会恢复。
3. 点击 **“框显周围展示”**。Blender 原生 Home 键只知道场景对象，无法把运行时 GPU 展示纳入框显，所以这里提供专用按钮。
4. 已完成的分类出现在鞋子附近；UNKNOWN 留在中心。鼠标中键旋转、滚轮缩放；触控板可使用自己现有的 Blender 导航方式。
5. 不要尝试点击周围展示网格，它们刻意不可选。要改已有分类，先让对应组件恢复原位，再在原网格上选择面。

### 哪些面会移到周围

满足以下全部条件才展示到锚点：

- 不是 UNKNOWN；存在已知的一级组件归属。
- `sgo_issue == 0`。
- 是 HUMAN，或打开“同时展示自动候选”时的 AUTO。
- 该组件选择“展开显示”，分类没有被管理器隐藏。
- 不是进入前用户使用 H 隐藏的面。

**问题面保持在中心，不作为已完成零件移走。**工作台内问题面不受分类隐藏按钮的默认过滤；进入前用户显式 H 隐藏的面仍保留隐藏。UNKNOWN 的隐藏/单独查看仍可由管理器主动控制。

关闭“同时展示自动候选”后，只展开 HUMAN；AUTO 回到中心，不改变标签或置信度。

## 布局控制

- “总分解距离”：整体拉开或靠近。只改绘制平移，不重建原网格。
- “调整一级组件”：选择鞋身、翻筒、鞋舌、鞋底、五金、鞋带或装饰，再调整固定偏移 X / Y / Z。
- 默认方向依据原模型旋转坐标：左侧为 **−Y**，上方为 **+Z**，前方为 **−X**；不是屏幕左右。轴向依据本次真实鞋模审计。
- 包围尺寸、原始轴和中心在第一次建立时保存，后续新增分类不会重算布局。
- 所有鞋身子类共享 UPPER 的平移；后跟皮条也按其真实分类层级属于鞋身。新增子类不会把其他组件挤走。
- “自动排列 / 恢复默认排列”：显式回到默认位置；只有你点击时才重置。
- “名称”“引导线”可关闭，颜色来自真实语义配置。
- 管理器每行新增两个图标：**展开 / 原位**、**只展开当前组件**。这两个按钮按所属一级组件执行；子类共享父组件锚点。原来的显示、单独查看、选择和锁定按钮保持独立。工作台内点击“选中本分类”时，会先让所属组件恢复原位，再在源网格上选中，避免选中不可编辑的展示。
- “恢复全部原位”仍留在工作台，但停止所有展开；“退出工作台”则恢复进入前的显示、选择、编辑对象集合和视口着色。
- “只展开当前组件”让其他组件回到原位；“单独查看”是管理器可见性过滤，两者含义不同。

## 标注与自动归位

1. 在中心点选或框选 UNKNOWN 面。检查面板中的“明确的编辑对象”；对于主体应为 `Shoe_TEST_V3`。如果实际活动对象与面板不一致，工具会拒绝写入。
2. 选择正确分类，点“指定所选面”。
3. 工具先写真实属性、颜色，再按对象 UUID 和稳定面 ID 回读验证；全部通过才提示成功，并更新临时展示。
4. 原来的 UNKNOWN 面从中心隐藏，加入对应组件，位置与已有面严格对齐。已有组件不会重新居中或改变比例。
5. 可打开“新归属飞行动画”；默认关闭以减少负担。总活动动画最多默认 2,000 个三角面，超出部分直接显示到位。动画只平移临时三角面。
6. 智能扩展仍先预览：可以反复减选、补选；预览阶段不会提前移走候选。补选确认和锁定、问题、其他人工分类保护继续有效。
7. 点击“确认最终选区”后，同样使用真实回读和失败回滚，再同步展示。
8. 撤销和重做后，工具按恢复后的真实属性重新同步；刷新可能需要一个计时周期或数秒。可点“校验真实数据并同步展示”。

显示失败与标注失败分别报告：已验证的标签不会因为显卡展示失败被假称未写入；显示失败会退出工作台并恢复中心显示。

## 保存、退出与恢复

- 保存工作工程会**先退出工作台**，恢复进入前的面隐藏/选区，再保存真实标签。下次打开后需要重新点击进入。
- Blender 原生保存也注册了相同的退出清理回调。它不会把 GPU 缓存写进工程。
- 切换工程、正常停用插件或重跑脚本时，旧工作台会清理。
- 对于异常恢复/自动保存文件，工程中有临时显示恢复记录；启用工具并读取后，会按稳定源对象 ID 恢复隐藏和选区。记录无法匹配版本时会提示，而不是猜测。
- 不会写回真实拆分结果；导出 GLB 始终只包含原始对象。建议**先退出工作台再导出**，以免导出器自身的“仅可见对象 / 仅所选对象”等设置受到当前编辑状态影响。
- 在新副本中继续保存；不要用 Blender 原生“另存为”手动指向旧版工程。工具的安全另存按钮会拒绝已有目标，但无法替代操作系统对所有任意另存路径的保护。

## 性能与当前限制

- 以每 **8,192 个稳定源面**为缓存块。小区域修改只重建受影响的块，不重新生成整鞋展示；显示过滤和撤销校验仍需要向量化扫描标签。
- 第一次进入要读取所有真实三角面，不能完全消除几秒的初始停顿。几何验证、真实属性回读也可能耗时；不是所有操作都瞬时。
- 预算是**临时显示的保守估算**，不包括 Blender 源工程和原生 BMesh 的全部内存。默认 768 MiB、2,000,000 个源面/显示三角面上限，进入前检查；调低预算不会自动缩小已分配缓存，下次进入生效。
- 运行时 CPU 缓存、GPU 缓存不会跨重启保留；已保存的锚点与真实标签会保留。
- 本版只支持语义彩色检查，不在周围展示原始 PBR 效果。退出后可切换原材质。
- 原模型没有的零件不会凭空生成；UNKNOWN 多并不代表程序应强行认定边界。
- 本次未获得你的 Mac 最新工作文件，只能在相同真实 `soul.blend` 几何及旧版兼容工作副本上验证；云端测试用的人工标签不会打包给你。
- Mac 5.2.3 / Metal 仍请本机验证。若周围没有显示，先看工作台错误消息；不要继续在看不清的情况下批量标注。

## 建议本地首次验收

在新副本中进入工作台 → 确认中心 UNKNOWN → 框选少量面改为 UPPER → 看它们加入鞋身 → 撤销/重做 → 智能扩展预览并取消 → 确认一批面 → 退出 → 保存 → 重开检查。

不需要也不应该先执行 Separate、应用修改器、重建 UV、删除原面或导入任何替代模型。
