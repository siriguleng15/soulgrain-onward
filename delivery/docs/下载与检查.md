# 从 iPad 到 Mac 检查

优先下载 C 检查版（累计包含 A、B）；需要分阶段复核时分别下载 A、B。

这是**部分修复检查版**：B 的上部内衬/鞋眼/包边、C 深折层/收口尚待修，不能替换正式资产。

1. 点击 `.blend` 下载链接，保存到 iPad 的“文件”。若 Safari 尝试预览，长按链接选择“下载链接文件”。
2. 在“文件”长按下载文件 → 分享 → 隔空投送 → 选择 MacBook Pro。
3. Mac 打开 Blender → 文件 → 打开，选中对应 `Soulgrain_Stage_*_REVIEW.blend`。
4. 右上角对象大纲搜索 `REPAIR_`，可单独选择新补片。物体名 `WORK_` 为真实旧几何的派生副本，未知面依然保留。
5. 修复层可以分别隐藏，检查新结构；请用“另存为”保存自己的复核文件。

报告/对比 ZIP 含同相机前后图、真实切片、线框、待修坐标、逐源面修改清单及校验结果。

可选的小型修复补丁包用于重放，能在 Mac 生成包含完整源归档场景的大工程；普通查看不必运行脚本。下载版只省略重复源归档，以便单文件直接下载，实际修复网格没有精简。
