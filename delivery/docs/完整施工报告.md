# Soulgrain Onward 首批真实几何修复施工检查报告

日期：2026-11-11。**本次已实施真实补面、目标旧面清理和新网格重建；不是单纯显示隐藏。A 为局部修复检查点，B、C 为部分完成检查点，整鞋尚未通过最终验收。**

## 1. 原件、定位与保护

完整阅读施工说明及 01—08 八张标注图，以指定 Release 的真实面级 HUMAN 标注定位。AUTO 只在包头局部、连续印花翻筒外表面及独立圆形金属鞋眼经几何和上下文复核后作为局部参考；没有对 UNKNOWN 做任何新的识别或标签写入。

原始模型：`SOUL.NEW.blend`，75,893,266 字节，SHA-256：
`725756904a0c71ee9c927b3e39332655c4cd175d3b9d55d0272ae70adb105183`

原始语义 JSON：5,244,468 字节，SHA-256：
`90974d192fe73a0b698669df41b7a849fd61e86438a33f6235adc85bd224959d`

原工程共 17 个对象、13 个 Mesh、1,499,039 个三角面。鞋头在 −X，模型高度为 Z；本文的 A 侧指 Y<0，B 侧指 Y>0，避免将截图左右误当坐标。没有可靠的实物标尺，因此距离均为模型单位，绝不宣称毫米精度。鞋长约 1.9 模型单位。

模型内标签与提供 JSON 对应。旧语义元数据中的法线缓存哈希与当前 Linux Blender 重算值在 12 个网格上不同，其余几何/拓扑/UV 基线未发现对应变化；没有把该缓存差异当作需要修复的几何。保存后的保护比较以同一运行时读取的真实原件为基准，并保留源文件字节哈希。

**全部 412,512 个原 UNKNOWN 面在每个修复工作副本中都保留，标签、原面 ID、UV 和几何没有被重新分类或批量删除。** 原 Release 和 JSON 从未覆盖。其它鞋舌、鞋带、鞋眼及装饰原网格未主动改造。

## 3. B：鞋身外壳与鞋腔（图 03—07）

先检查并保留经径向暴露分析核实的 HUMAN 外侧表面，再处理确定的小缺面。24 处后部闭环小孔沿实际边界三角化，新增 638 面；排除圆形通风/鞋眼候选和高风险前鞋带孔区域。

派生副本清理 HUMAN UPPER 中已定位的旧内部结构：旧错误脚底 12,050 面（包含经实际新足床交叉核实的额外 4 面），被外层遮蔽的内部旧片 86,775 面，共 98,825 面。全部旧面在完整源归档/原件中保留，逐对象、逐源面 ID 记录在 `stage-B-result.json`。这是局部物理表里分析，不是把旧标签重新归入其它类别。

新鞋腔采用规则环向/纵向布面及共享边界的曲面足床，经与已核实外壳的局部约束拟合。曾尝试的直接偏移和体素内衬出现交叉、凹点或碎孔，均淘汰，未作为交付成品。最终新增 **18,970 面，单连通、一个开放施工边界**，足床无未建面，鞋口未封盖，没有检出自交或与核实外壳/24 补片相交。

## 4. C：翻筒内面与间隙（图 08）

原翻筒外面不移动、不重拓扑、不修改其 UV、PBR。只在派生副本清理人工标记为 CUFF_INNER 的 69,579 个旧内面，再建立新的内层与试制接边条。

新内层根据已复核的连续外层及 B 外壳采样构建，采用模型比例的间隙约束。初始径向间隙 0.0057、参考内外偏移 0.0038；之后独立检查三维最近距离和三角面交叉，不能将径向距离冒充法向厚度。

部分位置在两侧受保护外壳之间本来就容不下新布层和正间隙；另一些深折层存在回折，单值径向采样不足以表达真实表里关系。初始 96 个采样点不满足间隙/厚度约束，相关新单元未建。进一步复查撤下与受保护原翻筒深折层冲突的新内面 1,282 面及其失去连接的新碎片 628 面，共 1,910 面，不改变任何受保护原外层或 UNKNOWN。

最终保留安全新内面 **34,754 面**、试制接边 **290 面**。独立复查：新内面与新接边各自无检出的非相邻自交；与核实鞋身外壳/新补片、全部原翻筒外层标签面均未检出相交。新内面至核实鞋身外壳的顶点和面心抽样最小距离约 0.001011 模型单位；这是抽样值，不是全表面距离的严格下界。

另按 10 个实际独立金属环的平面、轴向和净孔径检查新内层遮挡。8 处新内层需按原净孔径开通，另外 2 处轴线已开放；原金属环本身未改变。所有 10 条中心轴检查均保持开放。这不等于已认证整个鞋身上所有鞋眼的完整通孔结构。

**C 深折层、部分端部和完整收口仍未完成，不能认定内面闭合或四层结构在全鞋范围已连成完整布料。** 290 面仅是保留下来的接边段，并未宣称已与全部原边缘焊接。待修坐标与原因见 `stage-C-deep-fold-pending.json`、`pending-region-coordinates.json` 和红色定位图。

`C_four_layer_sections.png` 使用真实三角面与 X=0.40/0.58/0.72 平面的交线：鞋身外侧红色、新内衬绿色、原翻筒外层蓝色、新翻筒内层金色。图中断线和未完成区域保留可见，未画虚构的四块完整板代替网格。

## 6. 保护验证与显示规则

- 完整阶段工程内的源归档：原坐标、拓扑、UV、材质/贴图资源、原面 ID、标签均与读取原件时一致。
- 每一个仍保留的旧面：按原对象 ID 和稳定源面 ID 比较，三角形坐标、UV、原标签状态/置信度/问题标记、材质面索引一致。
- 原对象世界变换、原材质槽次序复核；非目标的 11 个原网格完整签名一致。
- 下载 REVIEW 版仅移除重复源归档场景以缩小体积，真实工作场景的所有 Mesh 与完整阶段工程匹配；并非用简模或临时显示代理替换。
- **新增面没有冒充 HUMAN 标注**，使用 `repair_is_new` 和独立修复对象保存；旧 UNKNOWN 不作补片几何来源。新增面有施工 UV 和中性材质，尚未完成与原纹理图集的无缝映射。
- 目标分区检查图只隔离相应目标几何和实际补片，明确排除了其它区域及 UNKNOWN；完整工作场景仍保留全部 UNKNOWN。`full_PBR_*` 为保留全几何上下文的原材质对照，旧杂面仍可能可见。隔离图不能被当作全模型已清理成功的证据。
- 原件保留其它结构的事实，不等于其它结构原先就没有几何错误。本轮没有顺带修改鞋带、鞋舌或五金。

## 7. 保存、回退与 Mac 检查

A、B、C 是累计检查点：B 包含 A，C 包含 A+B。回退 C 使用 B；回退 B 使用 A；回退 A 重新打开原始 Release。不要覆盖用户自己的 V1/V2 标注工程。

下载 `Soulgrain_Stage_A/B/C_REVIEW.blend`，隔空投送给 Mac，用 Blender 打开。右上 Outliner 搜索 `REPAIR_` 可选中真正的新结构；`WORK_` 为保留旧面 ID 的派生网格。材质预览模式可以查看原 PBR，实体模式适合检查表面。

如果希望重新生成包含完整 `SOURCE_UNCHANGED__ORIGINAL_LABELS` 回退场景的大工程，可使用附带的小型 `Soulgrain_Repair_Kit.zip`。无需 Codex 或额外第三方库，内含预计算实际补片、删除面清单、源版本保护、完整中文说明。只接受本次精确源版本，拒绝覆盖已有输出。

真实拓扑已经变化，原语义 JSON 继续作为原件的权威记录，不能直接覆盖导入新拓扑；请勿在修复场景运行旧自动识别/分解工具。

已在 Linux Blender 5.2.2 LTS 中实际生成、保存、重新打开 A/B/C，验证新网格与已检查施工数据一致、源/非目标数据保护成立；便携补丁亦以真实源工程重放验证。Mac Blender 5.2.3 尚未实机验证。原工程如有旧语义工具的后台处理，请在新 Blender 会话中进行检查。
