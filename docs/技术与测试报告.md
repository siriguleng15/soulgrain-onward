# Soulgrain Semantic V2.2.0 技术与实际测试报告

日期：2026-11-10。范围：V2.1.1 的显示层增量升级，不进行实体拆分、建模、UV 重排或网站修改。

## 基线与兼容性

- 完整继承 V2.1.1，基线脚本 SHA-256：`a574476bc3ae454044387b43c20156f3ed1f0047e0d8d7748a0781d26d1ab883`。
- 沿用 `soulgrain.face-semantics/1.0`、`_sgo_v1_meta`、`_sgo_object_id`。
- 不改变 `sgo_part` / `sgo_status` / `sgo_confidence` / `sgo_issue` / `sgo_source_face` 的类型或含义。
- 不迁移面索引，不替换对象 UUID，不改动人工确认状态。新增 `v22` 副本来源记录、固定布局与 UI 配置；临时显示恢复记录在正常退出/保存时删除。
- 保留 UNKNOWN、问题标记、锁定保护、原材质切换、候选识别、原生手动选择、可编辑的智能扩展、JSON、撤销/重做和版本校验。工作台内切换 PBR 要先退出。
- 完整 `.py` 是可直接运行的交付物；`v22_display_extension.py` 只是维护用增量源码，不要单独运行它。

## 显示架构

采用**运行时三角网格缓存 + Blender GPU 视口绘制**，而不是创建临时 bpy.data 场景对象。

每个显示片段记录：临时命名空间 `__SGO_V22_DISPLAY__`、会话 UUID、源对象 UUID、稳定源面 ID、真实三角形坐标、配置颜色、所属一级组件和 GPU batch。

源几何以真实 `mesh.loop_triangles` 三角化读取，仅用于展示；没有写回原网格。每个片段的坐标保留源世界空间坐标，不以片段中心重定位。展示时只应用一级组件的统一平移矩阵。因此新增面、不同源对象及同组子类都能严格对位。

临时缓存不是正式 Mesh 分离结果，没有实体厚度补面、独立布料边界、切缝或结构认证。临时边界只表示真实标签选出的面集。绝不自动填补 UNKNOWN。

GPU 展示不进入 bpy.data，不存在可误选或误导出的临时 Object / Mesh / Material，也不必为绕过 V2.1.1 的对象、材质保护而增加校验例外。原有严格源对象清单与资源指纹继续生效。

源显示过滤使用原生 BMesh 的可逆 hide 状态。源对象维持编辑模式以支持原生框选和面级纠错；返回对象模式会先退出工作台。

## 固定布局与层级

第一次根据整鞋原始对象矩阵、模型坐标及包围尺寸建立布局，保存资产 ID、原始旋转基、中心及特征尺寸。后续不依据当前分类面数重新计算。

一级组为 UPPER / CUFF / TONGUE / SOLING / HARDWARE / LACE / DECORATION。所属关系沿真实语义配置的 parent 查找，不按材质名或空间位置猜测。UNKNOWN 和无法归入已知父组的类别留在原位。

默认位置：鞋身 −Y、翻筒 +Y/+Z、鞋舌 +Z、鞋底 +Y/−Z，其他组使用独立固定偏移。整体距离与每组偏移均可配置；子类共享其一级组偏移。所有方向均相对原模型旋转基，不随屏幕相机变化。

## 完成状态与保护

只有已分类、AUTO/HUMAN 状态有效、无问题标记、符合自动候选开关、组展开且管理器可见的面才移至周围。进入前用户原生 H 隐藏的面不会被悄悄重新展示。

问题面不移走；工作台内保持在中心，除非进入前用户显式隐藏。锁定不等同于隐藏或完成：它继续约束真实标注写入。

手动写入复用 V2.1.1 的原生数据事务：明确源对象、稳定源面 ID、前值与颜色快照、保护检查、写入、独立真实回读、统计/显示过滤刷新、二次回读；失败按快照回滚并回读确认。

本版让智能扩展最终提交也复用同一事务，而不是仅凭操作返回 FINISHED。候选预览、减选、补选和取消均不触发展示归类。人工补选仍检查锁定、问题、其他人工标签和跨对象冲突。

只有 VERIFIED 事务才调用展示更新。若标签验证成功而 GPU 更新失败，保留已验证标签，退出显示工作台并报告显示故障；不报告虚假的标签失败或成功。

## 缓存与性能边界

- 源几何读取一次；按源对象 UUID + 每 8,192 个稳定源面分块。
- 小修改只重建受影响块内的组件片段；未变片段保持缓存对象。100 面案例只更新 1 个源块。
- 标签对比、可见性过滤使用向量化数组；撤销/重做和显式刷新读取真实标签后比较显示修订。
- 初次读取几何和完整版本校验仍是同步阶段，会停顿数秒；之后初始缓存按事件分片构建，带进度和 Esc 取消。不是后台线程，也不宣称所有百万面操作无阻塞。
- 默认源面/显示三角面上限 2,000,000；展示预算 768 MiB，进入前按每三角面 320 字节保守预估。该预算不包含 Blender 源模型、BMesh、撤销历史的全部内存；不是操作系统硬内存上限。
- 可关闭动画；默认关闭。临时动画总活动三角面数默认不超过 2,000。旧面保持最终锚点，新到达面单独短暂平移；绝不移动原顶点。

## 生命周期

进入前记录原生面隐藏、选择、编辑对象集合、活动对象、管理器过滤、原激活颜色和视图着色。

正常退出、原生保存、工具保存、打开其他工程、卸载和重跑脚本均移除绘制回调/缓存并恢复显示。保存不序列化 GPU 数据；重新打开需再次进入。

异常恢复文件使用源对象 UUID、固定拓扑版本和恢复记录恢复 hide / selection。测试发现 Blender 的 load_post 阶段可能已有 EDIT 标志但尚无可用 BMesh，已修正为在后续初始化完成的会话读取/视口计时周期恢复，避免过早访问 BMesh。

不存在可靠方法在 Blender 任意关闭、断电前执行 Python 清理，因此使用恢复记录，而不承诺进程被强制终止时还能执行卸载代码。记录版本不匹配会报告，不能匹配时不猜测源面。

## 真实数据与测试条件

使用此前审计的真实 `soul.blend` 几何及兼容工作副本，未重新生成替代模型。

- 原始工程：71,160,979 字节；SHA-256 `0d255d72f07d4b4ffc1d94908222e2ef3da506df7011812d985ad3c5c3d6c1ff`。
- 13 个源 Mesh，1,499,039 个三角面；主体 `Shoe_TEST_V3` 含 1,063,542 面。
- 已有候选分类来自先前工具，人工测试标签仅写入全新测试副本。没有获得用户 Mac 上最新私有标注工程，因此不能宣称逐字节验证了该文件。
- Linux Blender 5.2.2 LTS；4 CPU 配额、约 32 GiB 环境。实际 GUI 测试用 Xorg + Mesa 软件 OpenGL，不是 Mac Metal、不是纯静态编译，也不是只检查 FINISHED。

测试源码与逐条机器结果位于 `tests/`、`reports/*.json`。测试脚本使用本次云端数据路径，不是要求初学者在 Mac 重跑的安装脚本。安装和运行主工具不依赖这些路径。

### 已运行的主要用例

1. 从 V2.1.1 新建独立副本，全部原标签保持，旧文件与原模型 SHA 不变。
2. UNKNOWN 原位、分类展开、AUTO/HUMAN 切换、锁定、问题面和 13 对象编辑场景。
3. 全部展示坐标逐三角面比对源坐标；未创建任何额外场景 Object/Mesh/Material。
4. 100 个 UNKNOWN → HUMAN UPPER；真实稳定 ID、属性和颜色回读；其他全部主体面属性未改变；只重建 1 块，所有固定锚点不变。
5. 实际邻接扩展、预览不提前移动、人工修剪、补选及保护拒绝、最终提交的真实回读。
6. 原生撤销/重做与真实标签、中心可见性、临时展示同时恢复。后台 Undo 用显式检查点，GUI 键盘组合本身未模拟。
7. 管理器隐藏、恢复、组原位、只展开、距离变换、选择分类自动原位、明确对象选择和退出对象模式。
8. 注入真实回读失败：标签完整回滚，失败面不进入展示；注入显示失败：仅退出工作台，标签不变。
9. 原生 H 隐藏保留；工具保存与原生保存退出清理；保存重开后真实标签一致。
10. 模拟含显示恢复记录的异常文件，重新打开后精确恢复 hide/selection、保留语义数据。
11. 活动工作台卸载、重跑独立模块，回调不重复；插件 ZIP 安装/启用/停用。
12. 真正的 GUI shader 编译、所有 GPU batches 绘制、中文侧栏、飞行动画、退出清理。检查图仅为补充，不代替工具交付。
13. **工作台开启时实际 GLB 导出**：无材质的隔离验证产物仍为原始 13 Mesh、1,499,039 三角面，没有临时展示节点。该检查 GLB 不交付、不替代任何资产；PBR 未修改且另行指纹验证。

### 参考性能

以最终 `reports/real-model.json` 为准。本次约为：首次进入 6.26 秒，100 面回读提交并同步 2.95 秒，智能扩展预览 4.41 秒，扩展提交完整验证并同步 7.41 秒，完整保护检查 3.85 秒，正常退出含校验 4.39 秒。

首次约展开 776,297 个真实三角面，CPU 展示缓存 118,704,271 字节（113.2 MiB）。测试进程峰值约 3.4 GiB，包含源模型、BMesh 与撤销历史；不能据此承诺 Mac 相同速度或内存占用。

## 已知限制与下一步

- Mac Blender 5.2.3 / Metal 未实机验证；需用户按中文指南在新副本中验收后再考虑正式拆分。
- GPU 网格只能在三维视口中观察，不是可导出/可渲染的实体分解模型；暂不提供周围 PBR 预览。
- 自动语义识别没有因分解显示变得更准确；复杂融合边界仍应标为 UNKNOWN / issue，不会自动修复。
- 过窄侧栏会压缩名称及按钮；可以把侧栏左边界向左拖宽。原生密集线框在远处可能遮暗 UNKNOWN，放大中心后标注。
- 外部手工改写属性或脚本绕过本工具时，按“校验真实数据并同步展示”重新读取；几何变动会触发已有版本保护拒绝。
- 工具按钮拒绝覆盖旧输入文件；用户仍应避免用 Blender 原生另存为手动指定旧工程路径。
- 当前未执行正式拆分、建模、网站代码改动、主分支合并或部署。
